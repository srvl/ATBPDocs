New to Minecraft servers? This page explains the words you will see in our guides.

## Basic terms

- **Client**: the game on your own device. **Server**: the computer that players connect to.
- **Edition**: Java or Bedrock. **Version**: the number, like 1.21.
- **Mods** add content by changing the game files. **Plugins** run only on the server, so players install nothing.
- **Mobs** are living creatures. **Entities** also include things like arrows, boats and TNT.

## Java vs Bedrock

Java runs on PC and Mac and supports mods and most plugins. Bedrock runs on Windows, consoles and mobile. They do not normally join each other's servers, but Geyser lets Bedrock players join a Java server, see [GeyserMC](/plugins_and_modifications/plugins/geysermc).

## Game modes and difficulty

- **Survival**: gather resources, manage health and hunger.
- **Creative**: unlimited blocks and flying.
- **Adventure**: like survival, but you cannot normally break or place blocks.
- **Spectator**: fly through everything without interacting.

Difficulty goes from Peaceful to Hard and changes mob damage and spawning. See [Common server.properties Settings](/running_a_server/common-server-properties).

## Dimensions

The **Overworld** is the main world. The **Nether** is a dangerous fiery world reached by portal. The **End** is home to the Ender Dragon.

## Server software and customizing

Paper is best for most plugin servers, Fabric and Forge are for mods. See [Server Software Overview](/running_a_server/server-software-overview). Datapacks also change gameplay without mods, see [Datapacks](/running_a_server/datapacks), and resource packs change textures, see [Resource Packs](/running_a_server/resourcepack).

## Performance words

A healthy server runs at 20 ticks per second (TPS). **View distance** is how far players see, and **simulation distance** is how far things are active. Lower values reduce lag. Pre-generating your world helps too, see [Chunky](/plugins_and_modifications/multiplatform/chunky-multi).
