- **All servers are in Singapore.**

  ![Network Status, Philippine ISPs table: status and typical ping now for PLDT, Globe, Converge, Smart and DITO](/screenshots/network-status-isp-ping.webp)

- **Premium+:** AMD Ryzen 9 9950X (up to 5.7 GHz), DDR5 RAM at 3600 MHz (each machine holds four 64 GB sticks, so they run below their rated 5600 MHz), storage in RAID 1.
- **Budget+:** AMD EPYC 7B13, DDR4 2666 MHz RAM.
- **No VPS or VDS plans:** we do not sell VPS or VDS plans. Your server runs on hardware ATBP owns, split up with Proxmox, so strictly speaking it sits in a virtual dedicated space (VDS) on our machines. You manage it in your browser with the game panel (files, console, databases, SFTP). There is no remote desktop or root login, and you do not need one.
- **Web hosting:** in Singapore, with the HestiaCP panel. See [web hosting](/plans/web-hosting).
- **Bandwidth:** unmetered (no bandwidth limit, subject to fair use) on all game server and web hosting plans.
- **DDoS protection and firewall:** Budget+ and Premium+ servers are protected by TCPShield, which uses GSL. Our network blend in the data centre is also GSL, which adds basic GSL protection. Network firewalling and DDoS filtering are handled automatically — you do not need to configure a firewall yourself, and every port assigned in your **Network** tab is already open. We do not give out an address that skips TCPShield.
- **About ATBP Hosting:** operating since May 2025 and registered as a corporation in Canada, running our own bare-metal hardware in Singapore.
- **A host for the Philippines:** ATBP serves players in the Philippines, with prices in pesos and payment by GCash, Maya or a Philippine bank. The game servers themselves run in Singapore.
- There is no Philippines location. From the Philippines, ping to Singapore varies, usually about 30 to 80 ms. Players in the US or Europe will see about 150 to 180 ms; a VPN or proxy will not lower that.
- **Players in Europe or the US:** ping comes from the distance to the server that runs the game, and data can't travel faster than light through fibre. A proxy (Velocity, BungeeCord) or a subdomain like `eu.yourserver` in Europe, in front of a server in Singapore, does not lower their ping: their connection still goes all the way to Singapore, now with one more stop. Networks that give each region low ping run a full set of servers in each region (the game servers and a proxy in Europe, and another set in Asia), usually with separate worlds. We only have Singapore, so a European set would have to be hosted elsewhere.
- vCPU is capped, not burstable: 1 vCPU = 100% CPU in the panel (4 vCPU shows 400%).
- CPU Guardian: you can use your plan's full CPU at any time, and using all of it never gets a server limited. It halves a server's CPU only when a file on the server matches software known for heavy CPU use (such as a miner) while the server is working hard, or when staff limit it. A notice on the Console page says why and when your full CPU comes back. Fixed the cause? Ask in a ticket and staff can lift it early. Step by step: [CPU limit dropped to half](/running_a_server/troubleshooting/cpu-limit-halved).
- The panel shows which node your server is on under Settings. Whether each node is up is public at https://status.atbphosting.com, and the same page shows live whether lag comes from your ISP, our DDoS protection, the data centre or our servers.
- Moving a server to another node changes its IP (and sometimes ports). Ask in a ticket.
