title: "Server optimisation (free)"
---

- Optimisation help is **free** for all customers. We no longer sell a paid optimisation service.
- Start with the **Auto Optimizer** egg (panel > Settings > change server type). It tunes Paper/Leaf settings on every start. Note: it rewrites view and simulation distance each start; switch to the plain LeafMC egg if you want to set these yourself.
- For lag, open a Hosting Support ticket with a Spark report: run `/spark profiler --timeout 120`, then share the link. For lag spikes use `/spark profiler --only-ticks-over 100 --timeout 120`.
- Common fixes: lower view distance to 6 to 8, limit mob farms and entities, update plugins to versions made for your Minecraft version, and pre-generate your world with Chunky at night instead of during peak hours.
- Staff will tell you what the Spark report shows. Fixing third-party plugins or custom code is best effort.
- Optimisation and cleanup are free, so once we have optimised or cleaned your server the 3-day full refund no longer applies. See the [refund policy](/billing/refund-policy).
