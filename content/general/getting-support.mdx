title: "How to get support"
description: "How to reach ATBP Hosting support: Discord tickets, live chat, Messenger and email, and what to include so we can help fast."
---

- **Open a Discord ticket.** This is how we prefer to help. Open the ticket panel in **#create-a-ticket** on our Discord and pick the type that fits. Fill in the form, including your panel link for server problems. Mari, our AI assistant, may answer first from these docs, in tickets and in our chat channels. Staff still read every ticket and take over when you need a person.

  ![The Support Tickets panel in the create-a-ticket channel on Discord, with the Select a ticket type menu marked](/screenshots/discord-ticket-panel.webp)

  ![Discord ticket types: Hosting Support, Sales Inquiry, Server Renewal, Creator Partnership, General Inquiry and Server Optimization](/screenshots/discord-ticket-types.webp)

  - **Hosting Support**: server problems, crashes, connection, panel or network issues.
  - **Sales Inquiry**: billing, pricing and plan advice.
  - **Server Renewal**: renewing a server you already have. Only members with the Client role can open it, which you get by linking your Discord to billing with `/billing link` while you have an active service (a domain on its own does not count). If Discord says you lack the role, link your account first or pick **General Inquiry** instead.
  - **General Inquiry**: general questions, credits, top-ups and giveaway claims.
  - **Server Optimization**: ask for free optimization help for your server (there is no paid optimization).
  - **Creator Partnership**: partnership applications (1000+ followers).
- If Discord is not an option, use the **live chat** (the chat bubble at the bottom right of https://atbphosting.com, https://billing.atbphosting.com and the game panel at https://panel.atbphosting.com once you are logged in), message our **Facebook page** on Messenger, or **email** us.
  - Pick what you need help with before you start, so your chat reaches the right staff.
  - Leave your email if you can. If you close the page before we answer, the reply is emailed to you.
  - If you are logged in on billing or the game panel, staff can see your account, so you don't need to explain who you are. In the game panel they also see which server you have open, so start the chat from that server's page.
  - Mari, our AI assistant, answers first, from these docs, and links the page it used. In the game panel it answers for the game of the server you have open, so a Bedrock server gets Bedrock steps. Stock answers come straight from billing and match what checkout accepts. Under each answer, press **Yes, thanks** if it helped or **Talk to a person** if not. You can also type **agent** at any time. After a chat is passed to staff, the assistant can still answer new questions, but it stays out while staff are replying.
  - In the game panel chat, the assistant can also check a server that is not working. Tell it what is wrong and it reads that server's status, console, logs, crash files and settings files, with passwords, keys and addresses hidden, then tells you what it found. If it can fix the problem, for example a wrong setting or a server that needs a newer Java version, it shows the exact change and asks first. Reply **yes** to let it make the change, or **no** to do it yourself. Any other reply goes to our staff and nothing is changed. It keeps a copy of every file it changes, never deletes anything, and replying **undo** puts things back. It only checks servers you own, and only while you are logged in to the game panel. The result is written by AI and can be wrong, so read it before you say yes.
  - For lag, the assistant works from a Spark report. Paste the link if you have one. If you don't, it tells you how to make one: run `spark profiler start --timeout 300` in the console while the lag is happening, wait 5 minutes, and paste the link that appears. It then reads the report and tells you what is lagging. Without a report it will not guess.
  - Billing Balance and Server Renewal chats go straight to our staff.
  - Every chat also opens a ticket for our staff, so you get the same help as a Discord ticket.
  - On Messenger, staff can only reply within 24 hours of your last message, so reply to us there if you are still waiting.
- Please don't DM staff on Discord or their personal accounts; those messages are not tracked and may be missed. Messages to our Facebook page are tracked.
- Tickets close automatically after 12 hours with no reply; open a new one if you still need help.
- Link your Discord to billing with `/billing link` first so staff can see your services.
- For lag, include a Spark report: run `/spark profiler start --timeout 120` and share the link.
- We support the hosting itself. Help with third-party plugins, mods and server design is best effort.

## Is ATBP down?

- **Check the Discord announcements channel, https://status.atbphosting.com and https://atbphosting.com/network/ first.** When the game panel, billing or a node has a problem, staff post in announcements, and post again when it is fixed. The status page shows whether each node is up. The network page shows, live, whether lag or join problems come from your ISP (PLDT, Globe, Converge, Smart, DITO), our DDoS protection, the data centre or our servers.
- **If the game panel won't load, your server is most likely still running.** Game servers run on their own machines, so players can usually keep playing while the panel is down; you just can't use the console or files until it is back.
- **If only your server is unreachable**, check its console in the game panel first; most of the time the server crashed or is still starting. If the console looks fine and nothing is announced, open a **Hosting Support** ticket with your panel link.
- Don't reinstall your server or delete files while you wait. An outage does not delete your data.
