## Welcome to the ATBP Hosting docs

ATBP Hosting runs Minecraft and other game servers from Singapore, with billing in Philippine pesos and support on Discord. These docs cover how to pick a plan, pay, manage your server in the panel, and set up the games and mods you want to run.

Use the search button in the top right corner or press `CTRL+K` to find a page quickly.

---
