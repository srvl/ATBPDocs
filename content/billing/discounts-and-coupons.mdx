---
title: "Discounts, coupons and promo codes"
---

- **Codes that work right now** are listed on [Current promotions](/billing/current-promotions), which updates by itself, and show in a banner at the top of atbphosting.com and billing. No code listed means no public promotion is running.
- Old codes (for example 25OFF, LESS50, OCT40 or creator codes) no longer work.
- The discounts for longer billing terms always apply: **5% off for 6 months and 10% off for 12 months** on every plan (Budget+, Premium+, Terraria and Discord bots) and on paid Splits and Extra Backups. Checkout shows the saving under the term picker, for example "12 months: ₱1,512.00 (save ₱168.00, 10%)". 3 months is the monthly price times three, so it has no saving.
- The same term discounts apply when you renew in advance with the **Renew** button (see [renewals](/billing/renewals-suspension-and-deletion)), so prepaying 12 months costs the same as buying a 12-month plan.
- Enter a code at checkout or on the Renew page. A code comes off the price after the term discount.
- **What a code works on depends on that code.** Each one is set up for certain products and orders, for example new orders, renewals, renewals of several months at once, upgrades or domains. The announcement for each code says what it works on, and [Current promotions](/billing/current-promotions) lists it too. If billing does not take a code, it is not set up for that order.
- **Already have a renewal invoice?** You can still use a code on it. Open the invoice and press **Have a coupon code?** under **Pay** (or press **Renew** on your server), enter the code and press **Apply**. The same invoice drops to the discounted price, then you pay it as usual. Apply the code before you send a payment. A new code replaces one already on the invoice.
- **Once per customer:** most public codes, OCT25 included, can be used once per customer, on one server. Accounts that share a GCash or Maya number count as one customer, and a cart with more servers than the code has uses left is refused: order the others without the code.
- If a code ends before its invoice is paid, that invoice is cancelled and a new one is made at the normal price.
- New promotions are also posted in the Discord announcements channel.
