### What does the plugin do?

Floodgate allows Bedrock players to connect to Java servers running [GeyserMC](/plugins_and_modifications/plugins/geysermc), without a Java Edition account.

## Usage

[Download the plugin](https://geysermc.org/download/?project=floodgate) and upload the jar into your `plugins` folder. Restart or turn on the server. If you need help installing plugins, check out [this guide](/plugins_and_modifications/installing-plugins).  

Once you've installed the plugin, you will have to modify your GeyserMC config: in `/plugins/Geyser-Spigot/config.yml` (the plugin folder may be different), set `auth-type` to `floodgate`.

After that, restart your server; Bedrock players should now be able to connect to your Java server, without a Java Edition account.  

If you're using Tebex, you will have to change `username-prefix` to `*`. This is currently the only one Tebex supports, that will not cause conflicts with Java Edition accounts.
