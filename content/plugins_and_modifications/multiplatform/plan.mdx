### How to set up PLAN (Player Analytics)

Plan is an extremely popular & useful plugin that you can use to track server stats such as player counts, average playtime, and much more. You can check out the plugin [here](https://www.spigotmc.org/resources/plan-player-analytics.32536/).

This guide sets it up and gives it a free https address with a Web App subdomain.

#### Installation Steps:
1. Go to your ATBP panel, open the **Network** tab, and add a port from the **Bots and websites** range (see [Adding Ports](/using_the_panel/adding-ports)). Plan uses port 8804 by default; you will change it to this port in step 4.
2. Go to **More > Subdomain** and create a subdomain (for example `plan`) with **Type** set to **Web App** on that port. See [Web addresses (HTTPS)](/using_the_panel/ports-and-proxies).
3. Install the Minecraft plugin (linked above) and restart your server.
4. Open the plugin's config.yml and change the following values:
	- Webserver.Port: the port from step 1
	- Webserver.Alternative_IP: true
	- Webserver.Alternative_IP.Address: your subdomain from step 2
	- Webserver.Security.SSL_certificate.KeyStore_path: proxy

5. If you would like to track players’ locations:
`Data_gathering.Accept_GeoLite2_EULA`

That's it! Restart the server, open `https://` followed by your subdomain and click “Create Account” to make your account!
