## Requirements

In order to run Simple Voice Chat on your server, you need one of the following [server jars](/running_a_server/updating) installed:

- [Fabric](#fabric)
- [Forge](#forge)
- [Bukkit/Spigot/Paper](#bukkitspigotpaper)
- [Quilt](#quilt)

## Installation

### Fabric

1. Download the Fabric version of [Simple Voice Chat](https://modrinth.com/mod/simple-voice-chat/versions?l=fabric) ([Alternative download link](https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat/files/all?filter-game-version=2020709689%3A7499))
2. Open the [file manager](/using_the_panel/file-manager-controls) in your dashboard
3. Open the **mods** folder or create it if it doesn't exist
4. Drag and drop the **Simple Voice Chat jar** into the browser window.
5. Continue with the [common installation](#common)

### Forge

1. Download the Forge version of [Simple Voice Chat](https://modrinth.com/mod/simple-voice-chat/versions?l=forge) ([Alternative download link](https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat/files/all?filter-game-version=2020709689%3A7498))
2. Open the [file manager](/using_the_panel/file-manager-controls) in your dashboard
3. Open the **mods** folder or create it if it doesn't exist
4. Drag and drop the **Simple Voice Chat jar** into the browser window.
5. Continue with the [common installation](#common)

### Bukkit/Spigot/Paper

1. Download the Bukkit version of [Simple Voice Chat](https://modrinth.com/mod/simple-voice-chat/versions?l=bukkit) ([Alternative download link](https://www.curseforge.com/minecraft/bukkit-plugins/simple-voice-chat/files/all))

### Common

1. Make sure you followed the steps for [Fabric](#fabric), [Forge](#forge), [Bukkit/Spigot/Paper](#bukkitspigotpaper) or [Quilt](#quilt)
2. Open the **Network** tab in the panel
3. Click **Add port**, choose **Simple Voice Chat (UDP)** in the dropdown (see [Adding Ports](/using_the_panel/adding-ports)), click **Add port** again and note the port you get
4. Start the server once so Simple Voice Chat creates its config, then stop it. The file is `voicechat-server.properties`, in `config/voicechat/` on Fabric, Forge and Quilt, and in `plugins/voicechat/` on Bukkit, Spigot and Paper
5. Open that file in the [file manager](/using_the_panel/file-manager-controls) and set `port=` to the port you added in step 3, for example `port=24561`. Leave `voice_host=` empty
6. Start the server and check the console for **Voice chat server started at port** followed by your port. If you see it, Simple Voice Chat is installed

<Callout type="info">

Set `port=` yourself: adding a port in the panel does not put it in your config, and the default `24454` is not one of your ports. Keep `voice_host=` empty, or set it to your server's IP address, so voice goes straight to your server even when players join through a domain.

</Callout>

## Phone voice (VCMC)

The VCMC plugin (VoiceChatMobileClient) lets players on a phone join Simple Voice Chat. Its direct voice needs its own port, separate from the Simple Voice Chat port:

1. In the **Network** tab click **Add port** and choose **Simple Voice Chat (UDP)** in the dropdown again, so you get a second voice port
2. Start the server once so VCMC creates `plugins/VCMC/config.yml`, then stop it
3. Under `direct-voice:`, set `port:` to that second port (the default `24455` won't connect). Leave `advertised-host:` empty or set it to your server's IP address
4. Start the server again

## Voice chat doesn't connect

- Check that `port=` in `voicechat-server.properties` is a port listed in your **Network** tab, added with **Simple Voice Chat**. Not `24454`, and not your main game port. Restart after any change
- Make sure `voice_host=` is empty or holds your server's IP address, not an old address from a different server
- Every player needs the Simple Voice Chat mod on their game client
