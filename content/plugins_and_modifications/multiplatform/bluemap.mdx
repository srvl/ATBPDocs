## What does BlueMap do?
BlueMap is a program that reads your Minecraft world files and generates not only a map, but also full 3D-models of the whole surface.
With the web-app you then can look at those in your browser and basically view the world as if you were in-game!
Or just look at it from far away to get an overview.

It's an alternative to Dynmap or Squaremap, but unlike those, it is _fully_ 3D. You can orbit around everywhere, and fly through the world like spectator mode.

## Set up from the World viewer page

The panel can set BlueMap up for you on Paper, Spigot, Fabric, Forge and NeoForge servers.

1. Open your server in the [panel](https://panel.atbphosting.com) and go to the **World viewer** page.
2. Under **Set up the live map**, the page names the BlueMap build it found for your server software and Minecraft version and the folder it goes into. On Fabric it also adds Fabric API.
3. Press **Set up the map**. The panel downloads BlueMap, gives the map a port of its own, writes that port into BlueMap's `webserver.conf` and accepts BlueMap's download notice in `core.conf`.
4. Start or restart the server. The first render takes a while on a large world; the map then shows inside the **World viewer** page.

If your server cannot add a port by itself, add one in the **Network** tab first (see [Adding Ports](/using_the_panel/adding-ports)), then pick it on the page. If the page says no BlueMap build fits this server, there is no BlueMap release for that software and Minecraft version yet. If the map stays empty after a few minutes, check the **Console** for BlueMap errors.

## Manual install
Download BlueMap for your platform and install it like any other plugin/mod.
Config files for it will be generated in the `plugins/BlueMap` (plugin) directory or the `config/BlueMap` (modded) directory, depending on your platform.

Once it's installed, go to the `core.conf` file, and accept the EULA by setting the `accept-download` option to `true`.

By default, BlueMap will use an internal web server. It is recommended you don't change that unless you know what you are doing.

First, get a port for the map: open the **Network** tab in the panel and add a port from the **Bots and websites** range (see [Adding Ports](/using_the_panel/adding-ports)).

Then set BlueMap to use it. In the `webserver.conf` file, change the port (it is `8100` by default) to the port you were given:

```
port: 8100
```

Restart your server after you change the port.

You can also give your BlueMap an https address so nobody needs to type the port, with a free **Web App** subdomain. See [Web addresses (HTTPS)](/using_the_panel/ports-and-proxies).

For more information, the download link, their support Discord, the wiki and a demo, go to the [BlueMap website](https://bluemap.bluecolored.de/).
