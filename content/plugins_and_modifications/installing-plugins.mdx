This guide is for Bukkit/Spigot/Paper servers. If you are looking for instructions on how to install plugins on a BungeeCord/Waterfall or Velocity proxy, please see [this guide](/plugins_and_modifications/proxy-plugins).

### The Basics
> #### Requirements
> 
> In order to run plugins on your server, you have to be using a fork of Bukkit. (such as Spigot, Paper, Purpur, Pufferfish, etc. See our [guide on server jars](/running_a_server/jars) for more information.) If you wish to make client-side modifications (as well), see our guide on [installing server mods](/plugins_and_modifications/mods-install)!

> #### What are plugins?
>
> Plugins can be seen as addons which make changes to your Minecraft server. These changes can be as small as adding a simple info command or as large as a complete minigame.

### Plugin safety

Make sure you trust the source of your plugin. Plugins have full access to your server, so only download them from the official page of the plugin or its author. Do not use plugins from leak websites or "cracked" and "patched" re-uploads: these are the most common way a server gets a backdoor, and some of them copy themselves into every other plugin in your `plugins` folder.

#### Automatic backdoor removal

We check every server's plugins for known backdoors that hide inside normal-looking plugins. The check also covers your server jar (`server.jar`) and spare copies with a changed name, such as `Geyser-Spigot.jar.pre-geyser-update`. If your server has one:

- **A plugin you add is cleaned the moment it arrives.** This covers files uploaded in the panel or over SFTP, files downloaded from a link, renamed to `.jar`, or unpacked from an archive. Your console shows a line like `CPU Guardian: removed a backdoor from 1 new plugin file(s); 0 infected file(s) quarantined.`
- **Plugins already on your server are cleaned while it starts.** Your plugins, their settings and your worlds are kept; only the hidden code is taken out. Your console shows a line like `CPU Guardian: removed a backdoor from 3 plugin(s); 1 infected file(s) quarantined.`
- **If nobody is online, we restart the server for you** so the cleanup can run. We only do this when the server has 0 players, and at most once a day. If players are online, the cleanup waits for your next restart; you can restart it yourself at any time.
- **Removing a plugin is the last resort.** We always try to take out only the hidden code first, including in spare copies kept in other folders. A plugin is removed only when the backdoor is wired into it in a way that cannot be cut out safely, which is rare. If that happens, download a fresh copy from the plugin's official page and upload it again. Uploading the same file again will not help, because it is removed again.

If you see that console line, a plugin you installed came from an unsafe source. Replace your plugins with copies from their official pages, and check your server's operator list (`ops.json`) and permissions for anyone you do not recognise.

Some plugins check themselves and warn when they have been changed. For example, nLogin and nAntiBot print `THE PLUGIN LOADER HAS BEEN COMPROMISED`. Our team is alerted automatically when a server logs a message like that. A plugin we cleaned can keep printing it, because it is no longer byte for byte the file its author shipped. Download a fresh copy from the official page to make the message go away.

### Installing Plugins

The quickest way is the panel's own plugin installer:

1. In the [panel](https://panel.atbphosting.com), open your server and go to **More > Plugins**.
2. Search for the plugin. The filters at the top pick the source (such as Modrinth), your Minecraft version and your server software.
3. Install it, then restart your server. The **Installed** tab lists what you have.

![The panel's More > Plugins page: search, version and software filters, and a grid of Modrinth plugins to install](/screenshots/panel-more-plugins.webp)

To install a plugin by hand instead:

1. Download it from its official page, such as [Modrinth](https://modrinth.com/plugins), [Hangar](https://hangar.papermc.io/), [spigotmc.org](https://spigotmc.org/resources) or [bukkit.org](https://dev.bukkit.org).
2. Upload it to the `plugins` folder in your server's root directory, in the panel's **Files** tab or over [SFTP](/using_the_panel/sftp) (better for many files). If there is no `plugins` folder, create one.
3. Restart your server.

Once the server is online, type `plugins` in your console. If the new plugin's name shows in green, you're good to go. If not, see what to do below.

---

<Callout type="warning">

Starting with Paper 1.19.3 build 405, changes made to the plugin loader means that setups with cyclic plugin dependencies (where plugin loading causes a loading loop which will cycle back to the original plugin) will no longer function. A server with plugin dependency loops will not load and will be shut down with an error.

See the [Paper help page](https://docs.papermc.io/paper/reference/paper-plugins#cyclic-plugin-loading) for information on how to resolve the issue.

</Callout>

### What to do if a plugin doesn't load

In case you can't seem to be able to install a plugin properly, be sure to do these steps before asking for help.

1. **Check the plugins folder**: Confirm that the plugin has been uploaded to the plugin folder, and not accidentally uploaded elsewhere.
2. **Check your startup logs**: You should also check the startup logs as this can usually give you a hint to what’s wrong and causing a particular plugin to not start up properly. 
3. **Check if the plugin has any dependencies**: In a lot of cases, plugins require other plugins to run. Check console when the server is starting for an error stating there is a dependency the plugin requires. These should be listed on the website you got the plugin from. Simply download and install them the same way.
4. **Check for the plugin's version**: Even though most plugins after 1.13+ should be compatible with newer versions, this may not be the case with more sophisticated plugins. Be sure to check whether the plugin officially supports your Minecraft versions.
5. **Check for additional settings**: In some cases plugins require additional configuration before they can be loaded properly.
