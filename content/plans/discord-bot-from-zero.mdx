You bring your own bot code. We run it 24/7, but we do not write or set up your bot for you.

## 1. Log in to the game panel

Your server runs on the game panel at https://panel.atbphosting.com, not on the billing site. They are separate accounts with separate passwords.

- Your panel login is the email in the **"Your server is ready"** message. Check spam if you cannot find it.
- No panel password yet? Look for the email titled **Panel password inside**, or press **Forgot password** on the panel login page.
- From billing you can also open **Services**, pick your server and press **Manage server**.

Everything is in your browser. There is no remote desktop, and you do not install the server on your own computer.

## 2. Get your bot token

1. Open the [Discord Developer Portal](https://discord.com/developers/applications) and make an application.
2. Under **Bot**, press **Reset Token** and copy it.
3. Turn on any **Privileged Gateway Intents** your bot needs, such as Message Content. A missing intent is a common cause of a crash on start.
4. Under **OAuth2**, make an invite link with the `bot` scope and add the bot to your server.

Never paste your token in a public channel or a ticket. If it leaks, reset it.

## 3. Upload your files

Open **Files** and upload your bot, or use [SFTP](/using_the_panel/sftp). Zip it first and press **Unarchive** on the zip. Your start file must sit in the main folder.

Do not upload `node_modules` or a virtual environment folder. The server installs packages itself when it starts, from the files below.

## 4. Set it up on the Startup tab

| | Node.js | Python |
| --- | --- | --- |
| Start file | `MAIN_FILE`, for example `index.js` | `PY_FILE`, for example `app.py` or `main.py` |
| Package list | `package.json` in the main folder | `requirements.txt` in the main folder |
| Version | Docker image: Nodejs 24 or Nodejs 22 | Docker image on the same tab |

## 5. Add your token

Keep it in a `.env` file next to your start file:

```
DISCORD_TOKEN=your-token-here
```

Node.js reads this with the `dotenv` package. Python needs `python-dotenv` in `requirements.txt`.

## 6. Start it

Press **Start** and read the **Console**. When it logs in, your bot shows as online in Discord. It keeps running after you close the panel.

## 7. Database, dashboard and music

- **Database:** create one on the **Databases** page. It only works from servers on our network. See [Databases](/using_the_panel/databases). MongoDB Atlas works too.
- **Dashboard or webhook:** your app must listen on the port from the **Network** tab, on `0.0.0.0`. Other ports are not reachable. For a web address, make a free **Web App** subdomain in **More**, **Subdomain**.
- **Music:** pick **Lavalink** at checkout, or add a server split to run it next to your bot. See [Discord bot hosting](/plans/discord-bot-hosting).

## Common problems

| Message in the Console | What it means |
| --- | --- |
| `An invalid token was provided` or `Improper token` | Wrong token, or the `.env` file did not load. Reset it and try again. |
| `Used disallowed intents` | Turn on the intent in the Developer Portal. |
| `Cannot find module` or `ModuleNotFoundError` | The package is missing from `package.json` or `requirements.txt`, or the start file name is wrong. |
| `can't open file '/home/container/app.py'` or `No such file or directory` on a new server | The start file on the **Startup** tab does not match your file. Upload your code first, then set `PY_FILE` or `MAIN_FILE` to its exact name, such as `bot.py`. |
| `EADDRINUSE` or a dashboard that shows Error 522 | The app is on the wrong port. Use the port from **Network** and listen on `0.0.0.0`. |
| Killed, or exit code 137 | Out of memory. Lower usage or upgrade your plan. |
| `queryTxt ESERVFAIL` | See the MongoDB note on [Discord bot hosting](/plans/discord-bot-hosting). |

Errors inside your own code are yours to fix, or ask in that library's Discord.

## Still stuck?

Open a ticket on our [Discord](https://discord.atbphosting.com) with your panel link and the error from the **Console**. Never post your token.
