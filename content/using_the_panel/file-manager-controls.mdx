The **Files** tab of the [panel](https://panel.atbphosting.com) lets you browse, edit, upload and organise your server's files. For big uploads such as worlds or modpacks, [SFTP](/using_the_panel/sftp) is faster.

## Simple and advanced view

![The advanced file manager with the folder tree and file list](/screenshots/panel-files.webp)

The file manager has two views. Phones open the simple view and computers open the advanced view, until you pick one yourself. Your choice is saved in your browser, so another device or browser starts on its own default again.

- **Advanced** (the default on a computer): the full file manager with the code editor, search, the trash bin and the other tools on this page.
- **Simple** (the default on a phone): a plain list of files with a search row. It is lighter and easier on a small screen.

To switch to simple, open **File Manager Settings** (the gear button in the file list), go to **File manager** and pick **Simple**. To go back, press **Switch to advanced** in the bar at the top of the simple view.

In the simple view the search row can look in **This folder only** or **All folders**. Searching inside files (**File contents**) shows as greyed out when it is not available.

### Moving files in the simple view

Tick the files or folders, then press the move button on the bar that appears at the bottom, or choose **Move** in a file's menu (right-click or the `...` button). A folder picker opens: tap the arrow next to a folder to open it, tap a folder to pick it, then press **Move Here**. If the destination already has an item with the same name, the move fails and nothing is replaced.

![The Move window with a folder picked as the destination](/screenshots/panel-files-simple-move.webp)

## Browsing and selecting

- Click a folder to open it. Your current path is shown at the top; click any part of it to go back up.
- The `..` row at the top of a folder stands for the folder you are in. Deleting it deletes that whole folder and everything in it, and the list may keep showing the old files until you go back up or refresh. If you then upload into it, the folder is made again with only the new files. If a whole folder went missing, check the **Activity** tab for the delete and restore it from the **Trash Bin** (below) if it is there, or from a [backup](/using_the_panel/backups/guide).
- In File Manager Settings you can switch between the **Browse** view and a **Tree** view, choose whether folders open on a double click, and turn file checkboxes on or off.
- The grid button next to **Git** above the file list shows the files as a grid of tiles instead of a list. Your choice is saved in your browser; press the button again to go back to the list.
- Tick the checkboxes to select several files, or use the box at the top to select everything in the folder. **Clear selection** unticks them.
- Drag and drop files to move them, and drop files from your computer to upload them. You can ask to confirm before files are moved.
- Right-click a file, or use its menu, for **Rename**, **Duplicate**, **Move**, **Download**, **Archive**, **Unarchive** (`.zip`, `.tar.gz` and `.rar`; a file that was only renamed, or an archive damaged by an interrupted upload, fails with an extraction error, so upload it again or create a fresh archive at the source), **Properties** and **Edit chmod values** (file permissions).

  ![The file menu in the Files tab after a right-click, with Rename, Archive and Download marked](/screenshots/panel-files-right-click-menu.webp)

- Use **New File**, **New Directory** (a new folder), **Upload Files** or **Upload Directory** to add things. To use an SFTP program instead, press **Open in SFTP client**.
- **Upload Directory** (or dropping a folder) takes up to 500 files and 100 folders. For anything bigger, such as a modpack or a world, zip the folder on your computer, upload the single `.zip`, then right-click it and choose **Unarchive**. It is much faster and keeps every folder in place.

## Editing files

Open a text file to edit it in the built-in code editor. It has syntax colours, tabs for several open files, find and replace, and a **Show changes** view so you can check your edits before you save. Other things it can do:

- **Beautify** a config or script file (JSON, YAML, XML, HTML, CSS, SQL or JavaScript) to tidy its layout. JavaScript needs the Monaco editor, which you pick in the editor settings.
- **Preview** a Markdown (`.md`) file beside the editor; it follows your typing.
- **Find in Open Files**, and a **Recent and Modified** list of files you touched.
- **Pop out** opens the file in its own window.
- Open Minecraft `.dat` files (player data, level data) in an **NBT editor**.
- Open small SQLite databases (up to 32 MB) to view and edit rows. Changes are only saved while the server is stopped.
- Preview images, audio (with the song's title, artist, cover and a waveform you can click to jump), video and PDFs. Videos and PDFs over 200 MB play in a window that streams them, so they start right away.
- Look inside archives and extract only what you need. `.zip` and `.7z` files open like folders: tick files or folders inside and press the extract button on the bar at the bottom. `.tar`, `.tar.gz` and other tar archives open in an archive viewer (double-click, or **Browse archive** in the file's menu) where you tick files or folders and press **Extract**. Either way the files keep their folders from inside the archive, under the folder you pick.

In the simple view's editor, and in the editor on a phone, a row of round icon buttons above the text works on it. From left to right they are **Select all**, **Copy**, **Cut**, **Paste**, **Delete** (removes the selected text), **Undo** and **Redo**; hold or hover a button to see its name. They are handy on a phone, where selecting a long file by touch is hard. If your browser blocks clipboard access, **Paste** still inserts text you copied with these buttons in the same tab.

![The file editor with the Select all, Copy, Cut, Paste, Delete, Undo and Redo icon buttons above the text](/screenshots/panel-files-editor-buttons.webp)

Stop the server before editing a plugin or game config, or the server may overwrite your changes when it saves.

## Trash bin

Deleted files can go to the **Trash Bin** instead of being removed for good. Open it to find your deleted files and restore the ones you want.

- Deleted files in the trash still use your server's disk until the trash is emptied.
- Files that were in the trash before the [new panel](/using_the_panel/new-panel) (November 2026) are not shown in it.

## Share download links

Choose **Share download link** on a file to get a link anyone can download it from, without a panel account.

- Pick when it expires (1 hour, 1 day, 7 days, 30 days, a custom time, or never) and whether it allows any number of downloads or a set number.
- **Your active shares** lists your links; press **Revoke** to stop one.
- A link stops working if you lose access to the server's files or the server is suspended. The server owner can see and revoke every link on the server.

## Pull a file from a URL

**Pull from URL** downloads a file straight to your server, for example a plugin `.jar` or a modpack. Paste a direct link to the file, optionally give it a name and folder, and press **Pull File**. Very large files may be refused; use SFTP for those.

## Git

**Git** (the Git button above the file list) connects a folder of your server to a public Git repository, for example on GitHub.

- **Clone** copies a repository into your server. Paste its HTTPS link (such as `https://github.com/user/repo.git`) as the **Repository URL** and optionally a **Target Directory**. The target folder must be empty.
- **Pull** brings in new commits from the repository. If you changed files on the server that the update also changes, the pull stops and nothing is overwritten. It never pulls by itself; press **Pull** when you want the update.
- The panel shows the branch, **Remotes**, **Recent Commits** and the files you changed, with a before and after view of each change.

Only public repositories over HTTPS work. Private repositories, access tokens and SSH links are not supported, and you cannot commit or push from the panel. Cloning and pulling need both file and console permission on the server.

Git works best for files you only ever change in the repository, such as a Discord bot or a website. We don't recommend it for a Minecraft server: the game and plugins rewrite their own config and data files while running, and any file changed on the server that the repository also changes makes the next pull stop. If you do use it, make every change in the repository, never in the panel.

## File history

Where your server's node supports it, a file's history lists earlier saved versions. You can copy, download or **Restore** an older version.

## Files does not load or a folder is missing

- **The Files page will not load or shows no files:** do a hard refresh with **Ctrl+Shift+R**, or clear your browser's cookies and cache for the panel, then open **Files** again.
- **The world folder is missing:** a new server only makes its world folder the first time it starts. Start the server once, stop it, and go back to **Files**.

## Long tasks

Archiving, extracting, uploads, downloads, backups, restores and reinstalls show in a small task box on the screen with their progress, on every page of the server. You can keep working while they run, and the box still shows them after you reload the page. Press **Cancel task** to stop an archive, an extraction, a download, an upload or a reinstall. A backup or a restore runs to the end once started.

## Uploading a world or server zip

To move a world or a whole server from your own computer or another host, upload the `.zip` as one file in the **Files** tab, then right-click it and choose **Unarchive**. This is much faster than extracting it on your computer and uploading thousands of small files.

To move a whole Minecraft server folder:

1. On your computer, open the server folder and zip everything **inside** it (the `plugins` or `mods` folder, the world folders, `server.properties` and the rest), not the folder itself.
2. In the panel, stop the server. In **Startup**, set the same software and Minecraft version your server used, and a **Docker Image** that suits it. See [Changing Java Version](/running_a_server/java-version).
3. In **Files**, select everything and delete it. The new server's default files are not needed, and leaving them can mix two setups.
4. Upload your zip, right-click it and choose **Unarchive**. Check that `server.properties` and your folders sit directly in the main folder, not inside an extra folder. If they are inside one, the server cannot find its jar and will not start: open that folder, select everything in it, choose **Move**, pick the main folder (`/`), then delete the empty folder.
5. Delete the zip, start the server and read the **Console**. Players join with the address shown in the panel, not your old one.

- One upload through the panel can be up to 1 GB on Budget and Budget+, and 100 GB on Premium+. Use [SFTP](/using_the_panel/sftp) for anything bigger.
- Wait until the upload shows as finished in the task box before you unarchive or leave the page. A zip that is still uploading, or whose upload was cut off, cannot be opened.
- If **Unarchive** says the file is not a valid archive, the zip is incomplete or damaged. Delete it and upload it again. If it still fails, download it again from the old host, or upload it over [SFTP](/using_the_panel/sftp), which handles very large files better.
