The **Files** tab of the [panel](https://panel.atbphosting.com) lets you browse, edit, upload and organise your server's files. For big uploads such as worlds or modpacks, [SFTP](/using_the_panel/sftp) is faster.

## Simple and advanced view

The file manager has two views. Your choice is saved in your browser, so another device or browser starts in the advanced view again.

- **Advanced** (the default): the full file manager with the code editor, search, the trash bin and the other tools on this page.
- **Simple**: a plain list of files with a search row. It is lighter and easier on a phone.

To switch to simple, open **File Manager Settings** (the gear button in the file list), go to **File manager** and pick **Simple**. To go back, press **Switch to advanced** in the bar at the top of the simple view.

In the simple view the search row can look in **This folder only** or **All folders**. Searching inside files (**File contents**) shows as greyed out when it is not available.

## Browsing and selecting

- Click a folder to open it. Your current path is shown at the top; click any part of it to go back up.
- In File Manager Settings you can switch between the **Browse** view and a **Tree** view, choose whether folders open on a double click, and turn file checkboxes on or off.
- Tick the checkboxes to select several files, or use the box at the top to select everything in the folder. **Clear selection** unticks them.
- Drag and drop files to move them, and drop files from your computer to upload them. You can ask to confirm before files are moved.
- Right-click a file, or use its menu, for **Rename**, **Duplicate**, **Move**, **Download**, **Archive**, **Unarchive**, **Properties** and **Edit chmod values** (file permissions).
- Use **New File**, **New Folder**, **Upload Files** or **Upload Folder** to add things. To use an SFTP program instead, press **Open in SFTP client**.

## Editing files

Open a text file to edit it in the built-in code editor. It has syntax colours, tabs for several open files, find and replace, and a **Show changes** view so you can check your edits before you save. Other things it can do:

- **Format** a config file to tidy its layout, and show a **Markdown preview**.
- **Find in Open Files**, and a **Recent and Modified** list of files you touched.
- **Pop Out Editor** to edit in its own window.
- Open Minecraft `.dat` files (player data, level data) in an **NBT editor**.
- Open small SQLite databases (up to 32 MB) to view and edit rows. Changes are only saved while the server is stopped.
- Preview images, audio, video and PDFs, and look inside archives to **Extract Selected** files or a whole folder.

Stop the server before editing a plugin or game config, or the server may overwrite your changes when it saves.

## Trash bin

Deleting with **Move to Trash** puts files in the **Trash Bin** instead of removing them for good. Open it to search your deleted files, tick the ones you want and press **Restore**.

- The trash holds up to 500 items. When it is full, the oldest items are removed to make room, and it warns you when it is getting close.
- **Empty All** clears the trash for good. **Delete Permanently** skips the trash.
- Deleted files in the trash still use your server's disk until they are emptied.
- If automatic trash cleanup is offered on your server, File Manager Settings lets you turn it on and pick how old an item must be before it is removed.

## Share download links

Choose **Share download link** on a file to get a link anyone can download it from, without a panel account.

- Pick when it expires (1 hour, 1 day, 7 days, 30 days, a custom time, or never) and whether it allows unlimited or a set number of downloads.
- **Your active shares** lists your links; press **Revoke** to stop one.
- A link stops working if you lose access to the server's files or the server is suspended. The server owner can see and revoke every link on the server.

## Pull a file from a URL

**Pull from URL** downloads a file straight to your server, for example a plugin `.jar` or a modpack. Paste a direct link to the file, optionally give it a name and folder, and press **Pull File**. Very large files may be refused; use SFTP for those.

## File history

Where your server's node supports it, a file's history lists earlier saved versions. You can copy, download or **Restore** an older version.

## Long tasks

Archiving, extracting, big uploads and downloads, and backups show in a small task box on the screen with their progress. You can keep working while they run, and press **Cancel task** to stop one.
