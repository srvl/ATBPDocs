This page shows you how to set up 2FA on your account. Only set up 2FA on devices you trust, never on a shared or compromised device.

<Callout type="warning">

Write down the recovery code shown while setting up 2FA. Without it you cannot get back into your account if you lose your verification device.

</Callout>

## Game panel 2FA

![The panel Account page with Update Password, Update Email Address and Two-Step Verification](/screenshots/panel-account.webp)

To set up 2FA in the game panel, go to [Account Security](https://panel.atbphosting.com/account).

Hit **Enable 2-Factor Authentication** to show a QR code that you can scan.

For this, download a 2FA app on your phone, such as [Authy](https://authy.com/).

Then add a new account in the app and scan the QR code. Once it is scanned, type the token shown in the app into the Authentication Token box.

You are set and fully protected! Remember to keep the device near you when you log in so you can authenticate yourself.
