## Accessing the panel


![The ATBP panel sign-in page with the ATBP Hosting - Billing sign-in button](/screenshots/panel-login.webp)

You can access your server's main control panel [here](https://panel.atbphosting.com/). If you have multiple servers, you can choose which you want to modify from the panel page. Or, simply choose the server you want to control from the drop-down box of each page within the panel.

## Home


![The panel home page listing your servers](/screenshots/panel-server-list.webp)

This is likely your main dashboard or overview page for the server. It typically shows basic server status (online/offline), resource usage (CPU, RAM, disk), and perhaps quick access to server actions like starting, stopping, or restarting.

## Console


![The Terminal page with the console, address and resource cards](/screenshots/panel-terminal.webp)

This is a crucial feature for server management. The terminal provides a command-line interface directly to your Minecraft server console. Here, you can:

*   See server logs (e.g., player joins/leaves, chat messages, errors).
*   Execute server commands (e.g., `/op <player>`, `/gamemode <player> creative`, `/save-all`, `/stop`).
*   Monitor server activity in real-time.

## Files

This section allows you to manage the files and folders on your Minecraft server. You can:

*   Upload and download server files (e.g., world saves, plugin JARs, configuration files like `server.properties`).
*   Edit text files directly in the browser (e.g., plugin configurations, whitelist.json).
*   Create, delete, and rename files/folders.
*   Manage permissions for files if necessary.

## Databases

While not always required for a basic vanilla Minecraft server, many advanced setups and plugins (like economy plugins, some claim plugins, or BungeeCord/Velocity setups) utilize databases (e.g., MySQL or SQLite) to store persistent data. This section would allow you to:

*   Create and manage databases for your server.
*   Create database users and set permissions.
*   View database credentials for your server to connect to them.

## Schedules

This feature is incredibly useful for automating server tasks. You can set up schedules to:

*   Automatically restart the server at specific intervals (e.g., daily at 3 AM for maintenance).
*   Run backup commands at set times.
*   Send warning messages to players before a scheduled restart.
*   Execute other server commands periodically.

## Users

If you have multiple people managing your Minecraft server, this section allows you to:

*   Add new users to your Server panel.
*   Assign specific permissions to each user (e.g., allow someone to only view the console, or give another person full file management access).

## Backups

This is essential for disaster recovery. The backups section allows you to:

*   Create manual backups of your entire server (including world, plugins, and configurations).
*   Download existing backups.
*   Restore your server from a previous backup in case of data corruption or accidental deletion.

## Network

The Network tab lists your server's IP address and ports. From here you can:

*   See your main game port and any extra ports.
*   Add an extra port when a plugin or mod needs one (Geyser, voice chat, a web map), from a port range on nodes that use them. See [Adding Ports](/using_the_panel/adding-ports).
*   Add notes to a port, choose which port is the main one, and delete extra ports you no longer need.

## Startup


![The Startup page with the startup command, presets and variables](/screenshots/panel-startup.webp)

This is where you configure how your Minecraft server starts up. You can:

*   Select the Minecraft version or server JAR file to use.
*   Add Java flags to the startup command. Memory follows your plan's RAM: `-Xms` is fixed, and flags that hold all RAM from the start, such as `-XX:+AlwaysPreTouch`, are blocked on our shared machines.
*   Configure specific startup parameters for your Minecraft server (e.g., `nogui`, `online-mode`).

### Console time in your own time zone

The console shows times in UTC by default, so in the Philippines it is 8 hours behind. On a Minecraft Java server you can change this with a Java flag in the startup command:

1. Stop the server and open **Startup**.
2. In the startup command, add `-Duser.timezone=Asia/Manila` right after `java` or `-Xms128M`, and before `-jar`. Use your own time zone name if you are elsewhere, such as `Asia/Singapore`.
3. Keep a space on each side of the flag, and leave `-jar {{SERVER_JARFILE}}` exactly as it was, with its space. If the console says the jar cannot be found after the change, a space or character went missing.
4. Start the server. New console lines and logs use the new time zone.

Type the flag in by hand rather than copying it from a photo, since text scanned from a picture can add stray characters like `|`.

## Settings


![The Settings page with SFTP details, server name and Reinstall Server](/screenshots/panel-settings.webp)

This is a general settings area for your server instance. It might include:

*   Changing the server name displayed in the panel.
*   Reinstalling the server software (a clean slate).
*   Deleting the server.
*   Other general configuration options not covered by other specific sections.

## More

The **More** menu holds ATBP's extra tools. Which ones you see depends on your game and server type.

*   **Subdomain**: a free address for your server, or a **Web App** subdomain with https for a web map or website. See [Custom domains and free subdomains](/general/custom-domains-and-subdomains) and [Web addresses (HTTPS)](/using_the_panel/ports-and-proxies).
*   **Software**: change Minecraft software (Paper, Fabric, Forge and others) or version. See [Updating or Changing Versions](/running_a_server/updating).
*   **Plugins**: search for plugins and install them straight into your server. See [Installing Plugins](/plugins_and_modifications/installing-plugins).
*   **Splitter**: split your server into smaller servers. See [Splitting servers](/using_the_panel/split-server).

## Switching to a different game

To move a server to another game (for example from Minecraft to Terraria), open a Hosting Support ticket on our [Discord](https://discord.atbphosting.com) with your panel link and the game you want. Changing to another game deletes the server's files, so download anything you want to keep first. Your backups in the **Backups** tab are kept.

## Activity

This log provides an audit trail of actions performed on your server through the panel. You can see:

*   Who performed what action (e.g., server started, files uploaded, commands executed).
*   When the action occurred.
*   This is useful for troubleshooting and monitoring user activity.

Together, these tabs cover everything you need to manage a Minecraft server on the ATBP Hosting panel, from basic operations to advanced configuration and security.
