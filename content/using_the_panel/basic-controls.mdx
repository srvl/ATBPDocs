## Accessing the panel


![The ATBP panel sign-in page with the ATBP Hosting - Billing sign-in button](/screenshots/panel-login.webp)

You can access your server's main control panel [here](https://panel.atbphosting.com/). If you have multiple servers, you can choose which you want to modify from the panel page. Or, simply choose the server you want to control from the drop-down box of each page within the panel.

## Home


![The panel home page listing your servers](/screenshots/panel-server-list.webp)

The home page lists your servers with their status, CPU, RAM and disk use. Click a server to open it and start, stop or restart it.

The dot next to each server shows its status:

| Dot | Status |
|---|---|
| **Yellow** | Running and ready to join. Yellow is the ATBP theme colour, so yellow means all is well |
| **Orange** | Starting or stopping |
| **Grey** | Offline |

A server that stays orange for a long time is stuck starting; see [Server stuck starting, stopping or installing](/using_the_panel/stuck-server).

To put your servers in your own order, drag a server card and drop it where you want it. The order is saved to your account, so it is the same on every device.

### Page sections

When a page has its own sections (such as a server's sections, Network's Allocations, Firewall and Connections, Backups, or Account's Profile, Security and Preferences), where you switch between them depends on your screen size:

*   **Wide screens (1200 px and wider):** the sections appear in a grouped list beside the page. You can fold any group to keep it out of the way, and it stays folded.
*   **Narrower windows and phones:** one button shows the section you are in. Press it to open the section list (a bottom sheet on phones), with a search box when there are more than 12 sections.

The main sidebar stays on the side for top-level navigation.

### Keyboard shortcuts

| Keys | What it does |
|---|---|
| **Ctrl+/** or **Alt+/** | Show the keyboard shortcuts list |
| **Ctrl+Space**, **Alt+F** or **Ctrl+K** | Open quick actions and search |
| **Ctrl+.** | Go to your account page |
| **Ctrl+1** to **Ctrl+0** | Open the first to tenth server section (Console, Files, Databases, Schedules, Users, Backups, Network, Startup, Settings, Activity) |
| **Ctrl+1** to **Ctrl+4** | On account pages, open Account, API keys, SSH keys or Activity |
| **Alt+.** / **Alt+,** | Open the first two sections (Console and Files on a server, or Account and API keys on account pages) |
| **Alt+M** | Open Startup (inside a server) |
| **Alt+L** | Open Settings (inside a server) |
| **Alt+-** | Open Activity (inside a server) |
| **Alt+Z** | Start the server (on the console) |
| **Alt+X** | Stop the server (on the console) |
| **Alt+C** | Restart the server (on the console) |

You can change or turn off most shortcuts under **Account > Keyboard shortcuts** (`Ctrl+1` to `Ctrl+0`, `Ctrl+1` to `Ctrl+4`, and `Alt+Z`, `Alt+X` and `Alt+C` are fixed). Shortcuts are ignored while you type in a field, the console or the file editor.

## When a status page shows instead

While your server is busy or closed, every section shows one status page instead of its usual content, so nothing can fail halfway. This happens while the server is:

*   **Installing or reinstalling**: you see the current step, how long it has been running and the live install log.
*   **Importing** with the [Server Importer](/using_the_panel/server-importer): you see the percent copied, about how long is left and the current step.
*   **Moving to another node**: you see the percent copied, how much of your files have reached the new node, and how long it has been running. When the copy is done it shows the files being unpacked on the new node.
*   **Restoring a backup**, or on a node under **maintenance**.
*   **Suspended**: you see why and a button to pay. See [Suspensions and Terminations](/billing/suspensions_and_terminations).

You do not need to refresh. The page checks by itself and your normal sections come back when it finishes. You can also close it and come back later, as the work keeps going.

![The status page while a server installs, with the live install log](/screenshots/panel-status-installing.webp)

If the install fails, the page says so. See [Stuck on installing](/using_the_panel/stuck-server#stuck-on-installing).

## Console


![The Terminal page with the console, address and resource cards](/screenshots/panel-terminal.webp)

This is a crucial feature for server management. The terminal provides a command-line interface directly to your Minecraft server console. Here, you can:

*   See server logs (e.g., player joins/leaves, chat messages, errors).
*   Execute server commands (e.g., `/op <player>`, `/gamemode <player> creative`, `/save-all`, `/stop`).
*   Monitor server activity in real-time.

The small buttons above the console:

*   **Command history** (clock): the commands you sent on this server, newest first, each one listed once. The history is saved to your panel account, so it is there on any device you sign in from. Only you see it: a subuser has their own list. The last 200 commands are kept for 90 days. Click the arrow next to one to send it again, the copy button to copy it, or **Clear history** to empty the list. The Up and Down arrow keys in the command box go through the same list.
*   **Copy console**: copies everything the console is showing, up to its last 1,000 lines, as plain text. This is handy for pasting logs into a ticket.
*   **Clear console**: clears the console on your screen only. Your server and its log files are not touched, and the recent log comes back when you reload the page.

### Resource history

**Resource History** (on the console page) shows how your server has been doing over the last hour, 6 hours, day, week, month or year: how long it was running, starting, stopping or off, its CPU and memory (average and peak, against your plan's limit), network traffic in and out, and disk use. Drag across a graph to zoom into that stretch of time. History starts on 21 November 2026, when the panel began recording it.

When your server crashes, the panel notes it in the **Activity** section as a detected crash, so you can see when crashes happened even after a restart.

## Files

This section allows you to manage the files and folders on your Minecraft server. You can:

*   Upload and download server files (e.g., world saves, plugin JARs, configuration files like `server.properties`).
*   Edit text files directly in the browser (e.g., plugin configurations, whitelist.json).
*   Create, delete, and rename files/folders.
*   Manage permissions for files if necessary.

## Databases

While not always required for a basic vanilla Minecraft server, many advanced setups and plugins (like economy plugins, some claim plugins, or BungeeCord/Velocity setups) utilize databases (e.g., MySQL or SQLite) to store persistent data. This section would allow you to:

*   Create and manage databases for your server.
*   Create database users and set permissions.
*   View database credentials for your server to connect to them.

## Schedules

This feature is incredibly useful for automating server tasks. You can set up schedules to:

*   Automatically restart the server at specific intervals (e.g., daily at 3 AM for maintenance).
*   Run backup commands at set times.
*   Send warning messages to players before a scheduled restart.
*   Execute other server commands periodically.

## Users

If you have multiple people managing your Minecraft server, this section allows you to:

*   Add new users to your Server panel.
*   Assign specific permissions to each user (e.g., allow someone to only view the console, or give another person full file management access).

## Backups

This is essential for disaster recovery. The backups section allows you to:

*   Create manual backups of your entire server (including world, plugins, and configurations).
*   Download existing backups.
*   Restore your server from a previous backup in case of data corruption or accidental deletion.

## Network

The Network section lists your server's IP address and ports. From here you can:

*   See your main game port and any extra ports.
*   Add an extra port when a plugin or mod needs one (Geyser, voice chat, a web map), from a port range on nodes that use them. See [Adding Ports](/using_the_panel/adding-ports).
*   Add notes to a port, choose which port is the main one, and delete extra ports you no longer need.

## Startup


![The Startup page with the startup command, presets and variables](/screenshots/panel-startup.webp)

This is where you configure how your Minecraft server starts up. You can:

*   Select the Minecraft version or server JAR file to use.
*   Add Java flags to the startup command. Memory follows your plan's RAM: `-Xms` is fixed, and flags that hold all RAM from the start, such as `-XX:+AlwaysPreTouch`, are blocked on our shared machines.
*   Configure specific startup parameters for your Minecraft server (e.g., `nogui`, `online-mode`).

### Startup presets

The **Load a preset** list under the startup command holds ready-made commands: the ones your server type comes with (marked "(egg)") and the ones ATBP offers for it, such as our Java flag sets. Pick one and it replaces the startup command; restart the server for it to take effect. The list leaves out the command you already use. Our Java flag sets are made for Minecraft Java servers, so only pick one that suits your game: a command made for another game will not start your server. A preset follows the same rules as a command you type yourself, so one that is not allowed on your server's machine is not offered. **Reset** goes back to your server type's own command.

### Console time in your own time zone

The console shows times in UTC by default, so in the Philippines it is 8 hours behind. On a Minecraft Java server you can change this with a Java flag in the startup command:

1. Stop the server and open **Startup**.
2. In the startup command, add `-Duser.timezone=Asia/Manila` right after `java` or `-Xms128M`, and before `-jar`. Use your own time zone name if you are elsewhere, such as `Asia/Singapore`.
3. Keep a space on each side of the flag, and leave `-jar {{SERVER_JARFILE}}` exactly as it was, with its space. If the console says the jar cannot be found after the change, a space or character went missing.
4. Start the server. New console lines and logs use the new time zone.

Type the flag in by hand rather than copying it from a photo, since text scanned from a picture can add stray characters like `|`.

## Settings


![The Settings page with SFTP details, server name and Reinstall Server](/screenshots/panel-settings.webp)

This is a general settings area for your server instance. It might include:

*   Changing the server name displayed in the panel.
*   Reinstalling the server software (a clean slate).
*   Deleting the server.
*   Other general configuration options not covered by other specific sections.

## More

The **More** menu holds ATBP's extra tools. Which ones you see depends on your game and server type.

*   **Subdomain**: a free address for your server, or a **Web App** subdomain with https for a web map or website. See [Custom domains and free subdomains](/general/custom-domains-and-subdomains) and [Web addresses (HTTPS)](/using_the_panel/ports-and-proxies).
*   **Software**: change Minecraft software (Paper, Fabric, Forge and others) or version. See [Updating or Changing Versions](/running_a_server/updating).
*   **Plugins**: search for plugins and install them straight into your server. See [Installing Plugins](/plugins_and_modifications/installing-plugins).
*   **Splitter**: split your server into smaller servers. See [Splitting servers](/using_the_panel/split-server).

## Switching to a different game

You can switch your server to another game yourself in **Settings > Change Game**. The same box also changes the software of your current game (for example Paper to Fabric).

![Game panel Settings: Change Game, pick the game or software in the Egg list and press Apply](/screenshots/panel-settings-change-game.webp)

Every game costs the same per GB, so what decides a switch is your plan's size. Each game has a smallest plan on your tier (see [Premium+ sizes for each game](/plans/premium-plus-plans-and-prices#sizes-for-each-game) and [Budget+](/plans/budget-plus-plans-and-prices#sizes-for-each-game)):

*   **Your plan is at least that size:** the game is in the list. Pick it and confirm. For example a 6 GB Minecraft server can switch to Hytale, FiveM or Terraria, and back again.
*   **Your plan is smaller:** the game is shown below the list with what it needs, for example "Minecraft needs at least 6 GB on Premium+.", and an **Upgrade** button. Upgrading charges only the difference for the days left in your billing cycle. After paying, come back to Change Game and pick the game.
*   Switching to a game with a smaller plan does not lower your price. Your plan stays the same, so you can switch back later.
*   Switching itself is free and there is no limit on how often you switch. You only pay when you upgrade your plan.

Switching to another game reinstalls the server and **deletes all of its files**, so download anything you want to keep first. Your backups in the **Backups** section are kept. Your server's main port may change to one that fits the new game; a free subdomain follows it by itself.

You cannot switch while the server is busy or suspended. The page then says why (the server is installing, restoring a backup, being moved to another machine, or suspended) and the **Switch** buttons are off until it is done. Before you confirm a switch, the dialog names the image the new game or software runs on; if it has more than one, you can pick another on the **Startup** page afterwards.

Discord bots and databases stay what they are and cannot be switched to a game. Each split of a split server can run any game the main server's plan allows, see [Splitting servers](/using_the_panel/split-server).

## Activity

This log provides an audit trail of actions performed on your server through the panel. You can see:

*   Who performed what action (e.g., server started, files uploaded, commands executed).
*   When the action occurred.
*   This is useful for troubleshooting and monitoring user activity.
*   A file delete that fails partway still shows as a delete here, because some of the files may already be gone. Open the entry's details to see that it failed.
*   Files gone? See [Files or plugins went missing](/using_the_panel/backups/guide#files-or-plugins-went-missing).

Together, these sections cover everything you need to manage a Minecraft server on the ATBP Hosting panel, from basic operations to advanced configuration and security.
