---
title: "Server stuck starting, stopping or installing"
description: "What to do when a server will not stop, will not start, shows empty files, or stays on installing."
---

Most stuck servers come back with one of the steps below. Work through the section that matches what you see in the [panel](https://panel.atbphosting.com).

## Stuck on stopping

Some games, Palworld in particular, do not always react to the normal stop signal and sit on "stopping".

1. Press **Stop** and give it a full minute. Many games save the world before they close, and big worlds take a while.
2. If it is still stopping, press the stop button again. It now acts as **Kill** and ends the server straight away.
3. Start the server and watch the **Console** for errors.

Kill is like pulling the power cord. Anything not saved yet is lost, and in rare cases a save file is damaged. Use it only after a normal stop has had its chance. If you know you are about to stop, run the game's save command first (for example `save-all` in Minecraft, `save` in Palworld or Terraria, `saveworld` in 7 Days to Die).

If progress is missing after a kill, restore the latest copy from the **Backups** tab. See [Backups](/using_the_panel/backups/guide).

## "Another power action is currently being processed"

The panel is still working on your last start, stop or restart. Wait a few minutes (large worlds take longer to save), then refresh the page. Do not keep pressing buttons. If the message is still there after 10 minutes, open a ticket with your panel link.

## Will not start and Files looks empty

If the **Files** tab is missing the usual game folders, the game install was deleted or never finished.

1. Stop the server (kill it if it hangs).
2. Open **Settings** and press **Reinstall Server**.
3. Wait for the install to finish, then start the server.

A reinstall puts the game files back. It does not bring back a deleted world, so afterwards restore a backup from the **Backups** tab or upload your own copy of the world.

## Stuck on installing

A new server or a reinstall usually finishes in a few minutes; big games can take longer the first time.

- Leave it alone. Pressing Start or Reinstall again while it installs only makes it take longer.
- Refresh the page after waiting.
- If it still says installing after 30 minutes, open a ticket with your panel link. Staff can clear a stuck install.

## Game update broke the server

Steam games (Palworld, Rust, Valheim, 7 Days to Die, Project Zomboid, DayZ and others) download updates through SteamCMD. If an update fails or the server keeps starting an old version:

1. Stop the server and make a backup.
2. In **Files**, delete the `steamapps` folder in the main folder of your server. This clears the update cache only, not your world.
3. Open **Settings** and press **Reinstall Server**, then start the server.

## Disk full

If the console says there is no space left, or uploads fail with a disk error, your server is out of disk.

- Delete old logs, old backups you downloaded to the server, and unused worlds.
- Empty the **Trash Bin** in the file manager. Files in the trash still count against your disk.
- Look for plugin data that grows on its own: CoreProtect's database (move it to a MySQL database from the **Databases** tab), WorldEdit or FastAsyncWorldEdit history and schematics, and old `logs` and `crash-reports` folders.
- Check the world size. A world pre-generated far bigger than you need takes a lot of disk; set a world border, see [Limit world size](/running_a_server/limit-world-size).
- If you still need room, move to a bigger plan. See [Upgrades and downgrades](/billing/upgrades-and-downgrades).

### Disk completely full and the server is locked

When the disk is at 100%, the server cannot save, so it may hang on stopping, and the file manager may refuse to delete files.

1. If Chunky or another task is still running, run `chunky cancel` (or stop the task) in the **Console**.
2. Press **Stop**, then press it again to **Kill** the server.
3. Delete what you can from the file manager, then empty the **Trash Bin**.
4. If the panel still will not let you delete anything, open a Hosting Support ticket with your panel link and say the disk is full. Staff can free the space for you. Do not start a new pre-generation afterwards until you have checked it fits your disk.

## Wipe everything and start over

To start from nothing (a new modpack, a broken world, or just a fresh start), you can do it yourself in a few minutes. Staff do not need to do it for you.

1. Make a backup of anything you want to keep, or download it.
2. Stop the server.
3. In **Settings**, open the **Change Server Type** box, pick your software (for example Paper or Purpur) and an **exact version**, turn on **Wipe Server Files**, and install. This deletes every file and installs a clean server in one step.

Or do it by hand: in **Files**, tick the box at the top to select everything and delete it, then open **Settings** and press **Reinstall Server**.

A fresh install uses the version set in **Startup** or picked in **Change Server Type**. If that is "latest", you get the newest Minecraft version, which your plugins may not support yet. Set the version you want before you start the server, and before you upload an old world. A world that was opened on a newer version will not load on an older one; the server crashes or nobody can join. In that case restore a backup made before the change, or start with a new world. See [Updating or Changing Versions](/running_a_server/updating).

Deleted files that went to the trash can be restored from the **Trash Bin** until it is emptied. **Delete Permanently** cannot be undone.

## Still stuck

Open a ticket on our [Discord](https://discord.atbphosting.com) with your panel link, what you already tried, and a screenshot of the **Console**. See [How to get support](/general/getting-support).
