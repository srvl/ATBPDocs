title: "Adding Ports"
description: "How to add an extra port to your server from the Network tab."
---

Your server comes with one main port, and you can add more. Some plugins, mods and bots need another one, for example Geyser, a voice chat mod, a web map or a Discord bot dashboard. You add these yourself on the **Network** tab of the [panel](https://panel.atbphosting.com).

## How to add a port

![The Network page with the main port and the Add port button](/screenshots/panel-network.webp)

1. Open your server and go to the **Network** tab.
2. Click **Add port**.
3. Choose what the port is for from the dropdown. For **Minecraft Bedrock / Geyser** you also choose how many ports you need. Then click **Add port**.
4. Put the port you get in your plugin, mod or bot config, then restart your server.

If you see **Create Allocation** instead of **Add port**, click it to get a free port.

**No Add port button?** If you are a sub-user on someone else's server, the owner has to give you the network (allocation) permissions in **Users**, or add the port for you. See [Adding Sub-Users](/using_the_panel/users).

## Which one to choose

Each choice in the dropdown is a range of ports for one kind of use. The dropdown shows the protocol next to each name, for example **Rust (TCP + UDP)**, and once you pick one it shows the port numbers and how many are still free.

| Choose | Ports | Protocol | For |
|---|---|---|---|
| **Minecraft Java** | 25600 and up | TCP | Extra Java servers, for example behind Velocity |
| **Minecraft Bedrock / Geyser** | 19200 and up | TCP + UDP | Bedrock and Geyser, including the extra player ports a Bedrock server needs |
| **Simple Voice Chat** | 24500 and up | UDP | The Simple Voice Chat mod or plugin, and VCMC phone voice |
| **Votifier** | 8200 and up | TCP | Server list voting |
| **FiveM** | 30200 and up | TCP + UDP | FiveM servers |
| **Rust** | 28100 and up | TCP + UDP | Rust game, RCON and Rust+ |
| **ARK: Survival Evolved** | 7800 and up | UDP | ARK game and query |
| **Counter-Strike** | 27100 and up | TCP + UDP | Counter-Strike 2 |
| **Valheim** | 2500 and up | UDP | Valheim game and query |
| **TeamSpeak** | 10000 and up | TCP + UDP | TeamSpeak voice, query and file transfer |
| **Bots and websites** | 40000 and up | TCP | Discord and Telegram bots, web maps (BlueMap, Dynmap, squaremap), Plan, dashboards |
| **Other games** | 41000 and up | UDP | Any other game or service that uses UDP |

Each range has 100 ports (200 on some Budget+ servers, for example 25600-25799). **Minecraft Bedrock / Geyser** is bigger: 19200-19599 on Premium+ and 19200-19999 on those Budget+ servers. The choices are the same on Budget+ and Premium+. You get a free port from the range you choose; a specific or dedicated port number (for example `19132` or `24454`) is not sold. Not sure which one? Open a ticket on our [Discord](https://discord.atbphosting.com).

## TCP or UDP?

Yes, UDP is supported. Every port you add is opened for both TCP and UDP on your server. The protocol in the table and the dropdown is what that kind of traffic uses, so pick the choice that matches what you are running:

- Voice chat (Simple Voice Chat, VCMC), ARK and Valheim use **UDP**. Choose their own entry, or **Other games** for any other UDP game or service.
- Minecraft Java, Votifier, bots, web maps and websites use **TCP**. Choose **Bots and websites** for anything web or bot related.
- FiveM, Rust, Counter-Strike, TeamSpeak, Bedrock and Geyser use both, and their entries are **TCP + UDP**. A Bedrock server needs one port per player online at once, as one block of ports in a row. It already comes with one, and ports you add from **Minecraft Bedrock / Geyser** join onto it; see [Ports in a row](#ports-in-a-row) and [NetherNet](/games/minecraft-bedrock/connecting#nethernet).

After you add the port, put its number in your plugin, mod or game config. Most plugins don't pick it up on their own.

## Ports in a row

Some programs need several ports that follow on from each other, such as a Bedrock server's player ports. With **Minecraft Bedrock / Geyser** you choose how many ports you need, and you get them as one block in a row, for example 19300 to 19349. A server can have up to 50 ports in a row, and they don't count toward your server's port limit, so they never use up the ports in your plan.

- If your server already has ports in a row in that range, new ones join onto that block, so it stays one block. The dialog shows which ports they go next to.
- If the ports next to your block are taken by another server, the panel tells you. Open a ticket on our [Discord](https://discord.atbphosting.com) and we move your block to a free spot.
- On the Network tab, 3 or more ports in a row show as one line, such as **19300-19349, 50 ports in a row**. Click **Add ports** on that line to make the block bigger, or **Show ports** to see each port, change its notes or delete it.

## Moving an existing port

Your server's IP address cannot be changed, only its port. If people you don't want have your address, move your main port to a new one (below), recreate your subdomain on the new port, and turn on a whitelist.

Ports you already have keep working. To move one:

1. Add a new port, as above.
2. Put the new port in your config. For your main game port, click **Make Primary** on the new port instead.
3. Restart and check it works, then update anything that points at the old port (your server address or a domain's SRV record).
4. Stop the server, then delete the old port and start it again.

## Limits

Game servers come with 5 ports: your main port plus 4 you can add. Each split adds 3 more. Bedrock player ports in a row are not counted (see [Ports in a row](#ports-in-a-row)). Need more? Open a Sales Inquiry ticket on our [Discord](https://discord.atbphosting.com). The maximum for your server is shown on the Network tab. When you reach it, the choices that would need another port are greyed out in the dropdown, and so are choices that are full. Delete a port you no longer need to free one (you can't delete your main port). Stop the server before deleting a port: a running server keeps using its ports until it stops, so the panel won't remove one while it runs.
