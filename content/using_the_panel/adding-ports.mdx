title: "Adding Ports"
description: "How to add an extra port to your server from the Network tab."
---

Your server comes with one port. Some plugins, mods and bots need another one, for example Geyser, a voice chat mod, a web map or a Discord bot dashboard. You add these yourself on the **Network** tab of the [panel](https://panel.atbphosting.com).

## How to add a port

1. Open your server and go to the **Network** tab.
2. Click **Add port**.
3. Choose what the port is for from the dropdown, then click **Add port**.
4. Use the port you get in your plugin, mod or bot config, then restart your server.

If you see **Create Allocation** instead of **Add port**, click it to get a free port.

## Moving an existing port

Ports you already have keep working. To move one:

1. Add a new port, as above.
2. Put the new port in your config. For your main game port, click **Make Primary** on the new port instead.
3. Restart and check it works, then update anything that points at the old port (your server address or a domain's SRV record).
4. Delete the old port.

## Limits

Each server has a maximum number of ports, shown on the Network tab. When you reach it, **Add port** turns grey. Choices that are full are greyed out in the dropdown. Delete a port you no longer need to free one (you can't delete your main port).
