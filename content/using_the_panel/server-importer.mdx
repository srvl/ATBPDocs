The Server Importer copies files from another server straight into your ATBP server. Use it when you move from another host, or from one ATBP server to another (for example after changing plans), without downloading and uploading everything yourself. Your old server is not changed.

Open your server and go to **More > Importer**. There are three steps: connect, choose files, import.

## Step 1: Connect

You need three things from the server you are copying **from**:

| Box | What to enter |
|---|---|
| **Server address** | The SFTP address of the old server. Paste the whole thing, such as `sftp://user.1a2b3c4d@host:2022`, and the port, type and username are sorted out for you. A plain address such as `node.oldhost.com` works too: the panel finds the port by itself. |
| **Username** | The full SFTP username. On ATBP it is your panel username followed by a dot and the server ID. |
| **Password** | The password for that login. For an ATBP server this is your **game panel** password, not your email or billing password. |

- **From another host:** their panel or support shows these details, usually under **Settings** as SFTP Details.
- **From another ATBP server:** open that server on the [panel](https://panel.atbphosting.com) and go to **Settings**, see [Using SFTP](/using_the_panel/sftp).

Click **Connect**. If something is wrong, the message appears right under the box to fix. **Set the port or type yourself** is there for the rare server the panel cannot work out. Tick **Remember this server** to skip the typing next time; the password is never saved.

## Step 2: Choose files

The panel looks for your server's files and opens that folder, with everything ticked. Untick anything you don't want, or open another folder: whatever you tick in the folder on screen goes to the top of your server, so nothing ends up inside an extra folder.

- **Moving a big server from an old game panel?** Compress everything into one `.zip` or `.tar.gz` on the old panel first, then tick only that file. Copying file by file from a game panel can take hours; one archive takes minutes, and it is unpacked for you when it arrives.
- **Delete the files on this server first** empties the destination before copying, once the old server is confirmed reachable. [Make a backup](/using_the_panel/backups/guide) first if there is anything to keep.
- **More options** leaves out map renders, caches and logs if your server has them, turns off unpacking, or picks another destination folder.

Click **Start import**. Your server stops while the import runs.

## Step 3: Watch it copy

The page shows what it is doing, the percent copied and about how long is left, and updates by itself. You can close the page and come back; the import keeps going. While it runs, your server's other tabs show the same progress and a link back to the importer, with the live log for those who can reinstall the server.

- If the connection drops, the import retries by itself and carries on from where it stopped.
- If it stops for good, the page says why. Click **Retry** and it continues from there, keeping everything already copied. The Retry button on your other tabs brings you to the importer, where you may need to click it once more.
- When it ends, the next server tab you open shows once how it went, in that browser. Click **Continue to my server** to carry on.

## After the import

The importer copies files only, not the server's settings. Before you start the server:

- In **Startup** or **Software**, pick the same software and Minecraft version the old server used (Paper, Fabric, NeoForge and so on). Starting the files on different software can remove or ignore your mods and plugins. See [Server Software Overview](/running_a_server/server-software-overview).
- Pick the Java version that matches that Minecraft version, see [Java Version](/running_a_server/java-version).
- If mods or plugins still do not load, check the console for the first error and see [Installing Mods](/plugins_and_modifications/mods-install).

## Troubleshooting

- **"We could not reach" the address:** check the old server is online and the address has no typos. If it uses an unusual port, add it to the address, like `node.oldhost.com:2022`. Use the SFTP port, not the game port.
- **"That username or password was not accepted":** passwords are case-sensitive, and the username needs the part after the dot. For an ATBP server, reset your game panel password if you are not sure of it.
- **The import stops with "could not stay connected":** the old host may turn SFTP off for expired servers or block connections. Download your files from the old server as a `.zip` or `.tar.gz` instead, upload the archive in **Files** (or with [SFTP](/using_the_panel/sftp) for big files), then click **...** next to it and **Unarchive**.
- **"Finished, with some files skipped":** the old server refused those files, usually because they were locked or removed during the copy. The page shows the last one. Stop the old server and run the import again to pick them up.
- **It stopped at your disk limit:** an import cannot go past your plan's disk space. Import less, or see [Upgrades and Downgrades](/billing/upgrades-and-downgrades).

Still stuck? Open a [support ticket](/general/getting-support) with the panel link of the server you are importing into.
