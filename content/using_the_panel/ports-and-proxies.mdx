---
title: "Creating a Reverse Proxy"
description: "This guide will help you to create a reverse proxy."
---

import { Callout } from 'nextra/components'

<Callout type="warning">

Reverse proxies can only be used for *web connections* (eg. HTTPS). If you want to join your minecraft server using your domain, check [this page](/running_a_server/domain)

</Callout>
<Callout type="info">

For this guide, you must have access to a domain and the ability to alter that domain's DNS settings. In this guide, we assume you have a domain with Cloudflare, but most registrars will work.

</Callout>

---

First, go to your domain's DNS settings panel. In this demo, we use Cloudflare and **example.com** as an example domain.

The DNS record used for a reverse proxy is a CNAME (canonical name). In most cases, put an `@` in the Name box for a root domain, or the subdomain you want (for example `map`) for **map.example.com**.

Replace the '**Target**' field with the reverse proxy address shown in the **Ports & Proxies** tab of your server in the [panel](https://panel.atbphosting.com). If you are unsure which address to use, open a ticket on our [Discord](https://discord.atbphosting.com).

---

<Callout type="info">

CNAME records can take some time to propagate, though this depends on your ISP and other factors.

For more information, check out [this page](https://dnschecker.org/#CNAME).

</Callout>
<Callout type="warning">

If you use Cloudflare for DNS, set the 'Proxy status' to **DNS only**, as it won't work if it's proxied.

</Callout>

---

Once you've created your CNAME record, go to the [panel](https://panel.atbphosting.com) and select 'Ports & Proxies' on the left sidebar.

More than likely, you will have one allocation. To create a reverse proxy you need a new allocation: click '**Create Allocation**' and enter the port you want to use.

After creating the allocation and the DNS record, write the domain or subdomain you want to use for the reverse proxy in the "**Reverse Proxy Domain**" field in the **Ports & Proxies** section of the panel.
