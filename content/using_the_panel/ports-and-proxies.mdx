<Callout type="warning">

This is for *web* connections only (a web map, a dashboard or a website). To let players join your Minecraft server with a name instead of an IP, see [Custom domains and free subdomains](/general/custom-domains-and-subdomains) or [Using a domain](/running_a_server/domain).

</Callout>

Anything on your server that opens in a browser, such as BlueMap, Dynmap, squaremap, Plan or a bot dashboard, can get its own `https://` address. You set this up yourself in the [panel](https://panel.atbphosting.com).

## 1. Give the web plugin its own port

1. Open your server and go to the **Network** tab.
2. Add a port for it. For web maps, dashboards and websites choose **Bots and websites**. If the plugin's guide on this site names another port type, use that one. See [Adding Ports](/using_the_panel/adding-ports).
3. Put that port in the plugin's config and restart the server.
4. Check it works by opening `http://<your server IP>:<port>` in a browser.

## 2. Create a Web App subdomain

1. Go to **More > Subdomain**.
2. Type the name you want.
3. In **Type**, choose **Web App**. **Game Servers** is for players joining your server and does not give you https.
4. Choose the port you added in step 1, then create the subdomain.
5. Restart the server, then open `https://<your subdomain>` in a browser.

## If it still opens as http or does not load

- **Wrong type**: a subdomain made with **Game Servers** only points players at the server. Delete it and create it again with **Web App**.
- **Wrong port**: the subdomain must use the port of the web plugin, not your main game port. Delete it and create it again on the right port.
- **Changed the port later**: a subdomain keeps pointing at the old port. Delete it and create it again.
- **The plugin is not listening**: if `http://<IP>:<port>` does not open either, the plugin's config does not use that port yet. Fix the config and restart first.

## Using your own domain

To put a web plugin on a domain you own instead of the free subdomain, open a Hosting Support ticket on our [Discord](https://discord.atbphosting.com) with your panel link, the domain and the port.
