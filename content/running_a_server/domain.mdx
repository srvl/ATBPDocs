This guide shows you how to make your server go from lots of numbers (`203.0.113.10:25565`) to a domain name such as `play.example.com`.

First, go to the [game panel](https://panel.atbphosting.com) and select your server. On the main page, above your console you will be able to find your IP. Use the IP shown there. If your server runs on the default port (`25565`), you only need the IP and not the port. 

This guide uses Cloudflare to point our domain to the server. Simply register [here](https://dash.cloudflare.com/sign-up). After registration, they will guide you through the process of connecting your domain to Cloudflare.

Alternatively, some domain providers allow you to use their own systems for DNS. Though all sites look different, the task is the same for all of them. 

<Callout type="warning">

Make sure the record has a grey cloud (DNS only, not proxied by Cloudflare). You can still use Cloudflare, but a proxied record will not work for Minecraft.

</Callout>

---

- For the name, it will be `mc`. This is the subdomain which we have assigned to it, so whatever name we put there will be put before the domain when we type it in. In this case, it's `mc.example.com`. If you put `play` instead of `mc`, it would be `play.example.com`. 
- You can use `@` in the **Name** field if you want your root domain to point to your Minecraft server. A root domain looks like this: **example.com**
- Put the IP from your server into the IPv4 address field. Remember that you don't need to write your server port here.
- Lastly, double check that the cloud icon is set to 'DNS only'!

Click Save. This process will now take up to 48 hours to apply, but in most cases, it will be under a couple of minutes with Cloudflare!

## Pointing a domain to a server that doesn't use port 25565 (split servers or Essentials Plans servers)

If you have a split server or Essentials Plans server and it doesn't have a 25565 port, joining it directly needs an address to use something similar to this: `play.example.com:25566`. We can get around this by using a **DNS SRV record** that points to the split server port.

<Callout type="info">

You need an A record pointing to your server IP before you create the SRV record. If you haven't made one yet, follow the steps above first. SRV records only work for Java players; Bedrock clients cannot resolve them.

</Callout>

If you want multiple servers with clean domains on a network, [it's recommended to set up a network proxy](/running_a_server/velocity).

To create a DNS SRV record, head to your registrar or Cloudflare DNS configuration page. 
- Add a new DNS record and select `SRV`.
- Fill it in the same way as the A record above.
- Set the `Port` field to the port that your split server uses.
- Set the `Target` field to the subdomain or domain that points to your server IP.
- Priority and Weight can be left at `0`. TTL needs to be `Auto`.

That's all! Now you should be able to connect to your split server using `mc.example.com`. You no longer need to use the port.
