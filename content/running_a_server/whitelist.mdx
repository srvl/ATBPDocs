## What Is Whitelisting?

A whitelist is a list of players' usernames that are permitted to join the server while whitelist is on.

Whitelisting is a way to secure your Java/Bedrock server to ensure that only people that you want to connect to your server do. It is also how you stop new people from joining while the server is running: turn the whitelist on, add the players you want, and everyone else is turned away. It takes effect straight away, with no restart.

Whitelisting stops unwanted guests from joining your server, but it does not stop them from pinging your server and getting information such as online players and player count.

## Whitelisting On Java

### From the panel
On a Java server, open **More > Players** in the [panel](https://panel.atbphosting.com) and go to the **Whitelisted** tab. Add or remove players there; the panel keeps `whitelist.json` up to date for you. You still need whitelist turned on (`/whitelist on`, or `white-list=true` in `server.properties`) for it to keep others out. See [Make Yourself an Operator](/running_a_server/op-yourself) for a picture of the page.

### Offline (cracked) servers
On a server with `online-mode=false`, players are matched by their exact name, **including capital letters**. `Steve` and `steve` are two different players. Use the console instead of the Players page:

1. Ask each player for their in-game name exactly as their launcher shows it.
2. In the **Console** tab, run `whitelist add ExactName` for each one (no `/` in the console).
3. If you added a name with the wrong capitals, run `whitelist remove WrongName` and add it again.

Entries added on the Players page may not let cracked players in, because an offline server identifies players differently from a real Minecraft account. Adding them from the console avoids this. See [Offline Mode](/running_a_server/offline-mode).

### Whitelisted but still cannot join
- Check the kick message. "You are not whitelisted on this server" or "You are not authorized to join this server!" means the whitelist is on and the name on the list does not match the name the player joined with. Compare the spelling and capitals with `whitelist list`. Switching online mode does not change this; only the whitelist does.
- Did not mean to have a whitelist at all? Run `whitelist off` in the **Console**. Check `white-list` in `server.properties` too, since a world or config you uploaded can switch it on.
- A player who switches accounts in their launcher joins with a different name. Whitelist the name they are using now.
- After editing `whitelist.json` by hand, run `whitelist reload`.

### Bedrock players joining through Geyser
On a Java server with Geyser and Floodgate, add Bedrock players with Floodgate's own command. `/allowlist` is only for Bedrock servers and does nothing here.

1. Ask the player to try joining once, even though they are not on the list yet. They are turned away, but the **Console** now shows the exact name they joined with, in a line ending in "You are not whitelisted on this server!". It also lets Floodgate find their Bedrock account, which helps most when they changed their gamertag recently.
2. Copy the name from that line, **without** the `.` that appears in front of it in game.
3. In the **Console** tab, run `fwhitelist add BedrockName`.
4. Ask them to join again.

**Gamertags with a space** (for example `Steve Gamer`) must be put in quotes: `fwhitelist add "Steve Gamer"`. Do not swap the space for `_`, since that is a different name. The plain `whitelist add` command cannot take a name with a space (it answers "Incorrect argument for command"), so use `fwhitelist` for these players.

See [GeyserMC](/plugins_and_modifications/plugins/geysermc).

### With commands
To start off, here's a list of all the sub-commands under the whitelist command:
* `/whitelist add [player]` - Adds a player to the list
* `/whitelist list` - Shows you the current list of whitelisted players
* `/whitelist off` - Turns off the whitelist, which allows anyone to join
* `/whitelist on` - Turns on the whitelist, which allows only whitelisted players to join
* `/whitelist reload` - Reloads the cached list to match the list that is inside of `whitelist.json`
* `/whitelist remove [player]` - Removes a player from the list

### In Game
There are only 3 steps to turn on your whitelist in game:
* Step 1: `/whitelist on` - Turns the whitelist on.
* Step 2: `/whitelist add [player]` - Add someone to your whitelist.
* Step 3: Repeat Step #2 for all of your friends.

And that's it! Whitelist is now on, and only the people on the list can join your server!

### Through The File
Adding someone to whitelist through the file is a bit more complicated:
* Step 1: `/whitelist on` - Just like in game this will enable whitelist.
* Step 2: Open the `whitelist.json` file in your file editor. If you have never added someone before to the whitelist it'll look like this:
```yaml
[]
```
Otherwise, it'll look something like this (we will use Notch as a placeholder):
```yaml
[
  {
    "uuid": "069a79f4-44e9-4726-a5be-fca90e38aaf5",
    "name": "Notch"
  }
]
```
* Step 3: Add someone to your file. To do this you'll need their UUID. An easy way to get it is to go to a website like https://mcuuid.net/ and search their username. You will get a result page listing the player's UUIDs.

From that page, we need one thing, the user's Full UUID. Once you have that copied, you can head back to the `whitelist.json` file and add them to the file using this format:
```yaml
[
  {
    "uuid": "Their Full UUID",
    "name": "Their Username"
  }
]
```
If you plan on adding multiple users it'll look something like this:
```yaml
[
  {
    "uuid": "069a79f4-44e9-4726-a5be-fca90e38aaf5",
    "name": "Notch"
  },
  {
    "uuid": "Their Full UUID",
    "name": "Their Username"
  }
]
```

Notice the `,` after the `}` from the first user. Keep adding one after each player whenever you add a new player.

* Step 4: The final step is to go into the console and type `/whitelist reload`. This will make the saved file take effect!
* Step 5: Ensure that the list has been updated with `/whitelist list` and check to see that all the players you added are there!

## Whitelisting On Bedrock
<Callout type="info">

The command for whitelisting on Bedrock is `/allowlist`, not `/whitelist`.

</Callout>

To start off, here's a list of all the sub-commands under the whitelist command:
* `/allowlist add [player]` - Adds a player to the list
* `/allowlist list` - Shows you the current list of whitelisted players
* `/allowlist off` - Turns off the whitelist, which allows anyone to join
* `/allowlist on` - Turns on the whitelist, which allows only whitelisted players to join
* `/allowlist reload` - Reloads the cached list to match the list that is inside of `allowlist.json`
* `/allowlist remove [player]` - Removes a player from the list

### In Game
There are only 3 steps to turn on your whitelist in game:
* Step 1: `/allowlist on` - Turns the whitelist on.
* Step 2: `/allowlist add [player]` - Add someone to your whitelist.
* Step 3: Repeat Step #2 for all of your friends.

And that's it! Whitelist is now on, and only the people on the list can join your server!

Just like Java, adding someone to the whitelist through the file is a bit more complicated:
* Step 1: `/allowlist on` - Just like in game this will enable whitelist.
* Step 2: Open the `allowlist.json` file in your file editor. If you have never added someone to the whitelist before it'll look like this:
```yaml
[]
```
Otherwise, it'll look something like this (we will use Notch as a placeholder):
```yaml

    "ignoresPlayerLimit": false,

  }
]
```
* Step 3: Unlike Java, to add someone all you need is their username:
```yaml

```

Notice the `,` after the `}` from the first user. Keep adding one after each player whenever you add a new player.

### Keeping a player out of a Bedrock server
Vanilla Bedrock has no `ban` command, so `ban PlayerName` does not work there. To keep someone out:

1. While they are online, run `kick PlayerName` in the **Console** to remove them now.
2. Turn the allowlist on with `allowlist on` and add only the players you want (see above). Anyone not on the list cannot join again.

If you would rather ban players one by one, switch the server to **Endstone** in **More > Software**. Endstone runs the same Bedrock server with a `ban` command and plugins. Make a backup of your world before you switch. See [Endstone vs Vanilla](/games/minecraft-bedrock/endstone-vs-vanilla).
