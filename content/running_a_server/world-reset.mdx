title: "Resetting your worlds"
---

import { Callout } from 'nextra/components'

You'll need a way to access your server files. This tutorial references the [web panel](https://panel.atbphosting.com/), but you can also use SFTP. Shut down your server before proceeding.

<Callout type="warning">

Deleting a world cannot be undone. We recommend taking a backup of your old world before resetting, so you can restore it later if needed. Follow this [guide](/using_the_panel/backups/guide) to learn how to make and schedule backups. If you're sure you don't need the old world, you can skip the backup.

</Callout>

## Step 1: Go to the "Files" tab on your panel

Opening it shows the files and folders of your server.

## Step 2: Find the worlds to delete

On *most* Minecraft servers there are three world folders: Overworld (`world`), Nether (`world_nether`), and The End (`world_the_end`). If yours are named differently, check `level-name` in `server.properties`. Select the world(s) you want to delete with the checkbox on the left side of each folder.

## Step 3: Delete them

After selecting your worlds, click the Delete button that appears and confirm. Deleting these files should only take a few seconds at most.

## Optional step

Before deleting, you can archive your world by selecting the world folders first and clicking the Archive button at the bottom right of the file manager.

## Start the server

Once you've completed these steps, start your server again. The first start will take longer than usual as it generates a fresh world and spawn area.

If you wish to have multiple worlds on your server at once, add a suffix to the end of each world name (such as `_old`), or use a plugin such as [Multiverse](https://dev.bukkit.org/projects/multiverse-core).
