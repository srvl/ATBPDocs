This resets the world along with every player's inventory, location, stats and advancements, because they are saved in the world folder. Plugin data such as homes and balances stays in the `plugins` folder. To reset the whole server, including plugins and configs, see [Wipe everything and start over](/using_the_panel/stuck-server#wipe-everything-and-start-over) instead.

You'll need a way to access your server files. This tutorial references the [web panel](https://panel.atbphosting.com/), but you can also use SFTP. Shut down your server before proceeding.

<Callout type="warning">

Deleting a world cannot be undone. We recommend taking a backup of your old world before resetting, so you can restore it later if needed. Follow this [guide](/using_the_panel/backups/guide) to learn how to make and schedule backups. If you're sure you don't need the old world, you can skip the backup.

</Callout>

## Step 1: Go to the "Files" tab on your panel

Opening it shows the files and folders of your server.

## Step 2: Find the worlds to delete

The main world folder is named after `level-name` in `server.properties` (usually `world`). Which folders to delete depends on your software and Minecraft version, which the **Software** page shows at the top.

![server.properties in the panel editor with the level-name line marked](/screenshots/panel-editor-level-name.webp)

| Your server | Delete these folders |
| --- | --- |
| Paper, Purpur or Spigot on 1.21.11 or older | `world`, `world_nether` and `world_the_end` |
| Paper or Purpur on 26.1 or newer | `world`, plus `world_nether` and `world_the_end` if they are still there |
| Vanilla, Fabric, Forge or NeoForge (any version) | `world` |

Why the difference:

- **1.21.11 and older:** Paper and the other plugin servers keep the Nether and the End in their own folders next to `world`. Deleting only `world` resets the Overworld and keeps the other two.
- **26.1 and newer:** Paper keeps all three dimensions inside `world`, in `world/dimensions/minecraft/overworld`, `the_nether` and `the_end`. Deleting `world` resets everything. When an older world is updated to 26.1, Paper moves `world_nether` and `world_the_end` into `world` on the first start. Delete any that are left over, or an old Nether or End can come back in the new world.
- **Vanilla and modded:** the Nether and the End have always been inside `world`.

Only want a new Nether or End? See [Reset the Nether or End](/running_a_server/reset-nether). Running Bedrock? See [Delete or reset your Bedrock world](/games/minecraft-bedrock/delete-world).

## Step 3: Delete them

Tick the box on the left of each folder, click the **Delete** button that appears and confirm. Deleting these files should only take a few seconds at most.

## Optional step

Before deleting, you can archive your world by selecting the world folders first and clicking the Archive button at the bottom right of the file manager.

## Keep the same seed

If `level-seed` in `server.properties` has a value, the new world uses that same seed. If the line is blank, the new world gets a **random** seed. To get the same terrain again, run `seed` in the **Console** before you delete anything, then put that number on the `level-seed=` line while the server is stopped. To use a different seed, see [Change Your World Seed](/running_a_server/change-world-seed).

## Start the server

Once you've completed these steps, start your server again. The first start will take longer than usual as it generates a fresh world and spawn area.

If you wish to have multiple worlds on your server at once, add a suffix to the end of each world name (such as `_old`), or use a plugin such as [Multiverse](https://dev.bukkit.org/projects/multiverse-core).
