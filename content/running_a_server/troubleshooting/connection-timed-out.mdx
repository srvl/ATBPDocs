---
title: "Connection Timed Out"
description: "Fix the Connection timed out error when joining your server."
---

This means your game could not reach the server in time.

## Check the basics

1. **Is the server online?** Open the [panel](https://panel.atbphosting.com) and confirm the status is running. If it is stopped or still starting, wait for it to finish.
2. **Restart the server** from the panel and try again after it fully starts.
3. **Check the address.** Copy the IP and port exactly from the panel. If the port is not 25565, add it, for example `address:25566`.
4. **Use Direct Connection.** In Minecraft, choose **Direct Connection** instead of saving the server and paste the address.
5. **Check your version.** See [Outdated Server or Client](/running_a_server/troubleshooting/outdated-server-client).

## If it works for others but not you

Your own internet or route may be the problem.

- Restart your router or try mobile data.
- Turn off VPNs, or try a different one.
- Run a latency test, see [Diagnosing Ping Issues](/extras/ping-issues).

## If nobody can join

- Look at the console for crashes or errors.
- Make sure a custom domain points to the right address, see [Custom Domain](/running_a_server/domain).

Still timing out? Open a [support ticket](/general/getting-support) with your log, see [Share Your Server Logs](/running_a_server/share-logs).

## If only some players cannot join

- Our network protection can block individual IP addresses. Ask an affected player for their public IPv4 address (from any "what is my IP" site) and a few minutes of MTR results, see [Diagnosing Ping Issues](/extras/ping-issues), then open a ticket with both so we can check.
- Ask them to test on mobile data or another network. If it works there, their ISP route is the cause.
- Check https://status.atbphosting.com for regional network incidents.
