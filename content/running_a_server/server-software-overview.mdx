The server software (the jar file) decides which features and mods your server supports. For install steps, see [Server Jars](/running_a_server/jars).

## For plugins and best performance

- **Vanilla**: Mojang's own server with no changes. Good for pure survival with a few friends, but it lags sooner and has no plugin support.
- **Spigot**: an older optimized server that supports plugins. Most people now choose Paper instead.
- **Paper**: the recommended choice for most servers. Faster than Spigot, fixes many exploits, runs Bukkit and Spigot plugins and has built-in anti-xray.
- **Purpur**: a fork of Paper with many extra options you can toggle. Great if you want to tweak gameplay without extra plugins, though it takes more configuring.

## For mods

- **Fabric**: lightweight and quick to update. Good for performance mods and many modern mod packs.
- **Forge** and **NeoForge**: heavy-duty mod loaders used by many big modpacks. NeoForge is the modern continuation for newer versions.

Players usually need the same mods installed on their own game. See [Installing Mods](/plugins_and_modifications/mods-install).

## Special setups

- **Proxies** (Velocity, Velocity-CTD, BungeeCord): connect several servers together. See [Velocity](/running_a_server/velocity).
- **Hybrids**: try to run mods and plugins together. See [Hybrid Servers](/running_a_server/hybrid-servers).
## For Bedrock

- **Vanilla Bedrock**: Mojang's official Bedrock Dedicated Server. Players join from phones, consoles, Windows and the other Bedrock apps.
- **Vanilla Bedrock (Preview)**: Mojang's preview builds. Only players on the Minecraft Preview app can join, so use it for testing, not your main world.
- **Endstone**: a Bedrock server that runs Python and C++ plugins. It installs the Bedrock version that matches the Endstone version you pick.

Java and Bedrock players can also share one Java server with Geyser, see [GeyserMC](/plugins_and_modifications/plugins/geysermc).

## Switching software or version

Open your server on the [panel](https://panel.atbphosting.com) and go to **Versions**. Pick the software, then the version and build, and press install.

- [Make a backup](/using_the_panel/backups/guide) first. Worlds do not carry over between Java and Bedrock.
- Your files stay unless you turn on deleting server files. When you move between Java and Bedrock, the old `server.properties` is renamed (for example to `server.properties.java`) so the new software starts with its own.
- Bedrock and Endstone install through the server installer, so the server shows as installing for a minute or two. Start it when that finishes.
- Endstone is not available on every node. If it will not install on your server, open a ticket.

## Quick pick

| You want | Choose |
|---|---|
| Plugins like ranks, claims, shops | Paper |
| Extra gameplay options | Purpur |
| Light mods | Fabric |
| Big modpacks | Forge or NeoForge, depending on the pack |
| Unmodified game | Vanilla |
| Bedrock players (phones, consoles) | Vanilla Bedrock |
| Bedrock with plugins | Endstone |
