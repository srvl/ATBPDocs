What does the plugin do?
[Spark](https://www.spigotmc.org/resources/spark.57242/) is a performance profiling plugin (with limited availability for Forge and Fabric) that can display server information, such as TPS, memory, tick durations, CPU usage, and disk usage. More importantly, it can create a performance profile that can be viewed on a full-featured web interface. It does not require any configuration and is incredibly easy to install.

## Setup

You can skip this step if you are running Purpur 1.19.1 or above. Paper 1.21+ also includes Spark by default, so you do not need to download it separately.

Download the latest build from [Spark](https://spark.lucko.me/download) and drop it into your plugins folder (or mods folder if you are running Forge/Fabric). Turn on or restart the server, and you're done! If you need help installing plugins, check [How to install plugins](/plugins_and_modifications/installing-plugins).

## Using the profiler

Some versions of Spark use different command roots: `/sparkb` for BungeeCord, `/sparkv` for Velocity, and `/sparkc` for Fabric/Forge. If you are having trouble running the command, try the matching command for your platform.

The most useful tool in terms of diagnostics is the profiler feature, which can be run with `/spark profiler start`.

Usually you'll want to run the profiler during a time of stress for your server. To get the most out of the report, leave it running for 10 minutes or more. You can also add additional parameters to the report; for more information check the [Spark Documentation](https://spark.lucko.me/docs/Command-Usage).

Once you are ready to check the results of the profiler, run `/spark profiler stop` and copy the link produced.

When you open the link you'll find a useful web interface that displays all the data collected.

## Other useful commands

Running `/tps` will display your server's current TPS (ticks per second) and related tick information.

Running `/spark healthreport` will display a summary of your server's health, such as TPS, memory, CPU and disk usage.

The values will depend on your server. Newer versions of Spark will contain more useful information, as the utility is in active development.

For more parameters and other useful commands, check the [Official Spark Documentation](https://spark.lucko.me/docs/Command-Usage).

## Need help reading the profile?

Paste your profile link into the [Spark Analyzer](/running_a_server/spark-analyzer). It lists what is lagging the server and which settings to change. If you still need help, create a ticket in our [Discord](https://discord.atbphosting.com) with the link.
