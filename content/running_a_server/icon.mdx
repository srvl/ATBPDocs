---
title: "Adding an icon"
description: "Set the picture players see next to your server in the Minecraft server list."
---

The server icon is the small picture next to your server in the Minecraft multiplayer list. The panel makes it for you:

1. Open your server in the [panel](https://panel.atbphosting.com) and go to the **Files** tab.
2. Click **Change Icon** and pick a PNG or JPEG image.
3. Drag the crop box to the part you want. The panel resizes it to 64x64 and saves it as `server-icon.png` in your main folder.
4. Restart your server. Players may need to refresh their server list to see it.

Making the file yourself also works: a 64x64 PNG named exactly `server-icon.png`, uploaded to the main folder (next to `server.properties`).
