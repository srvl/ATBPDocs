Most basic server options live in `server.properties`. To edit it:

1. Stop the server (changes made while it runs can be overwritten).
2. Open the **Files** tab and click `server.properties`.

   ![Game panel Files tab with server.properties marked in the file list](/screenshots/panel-files-server-properties.webp)

3. Change the line you need, save, and start the server again.

   ![server.properties open in the panel editor with the difficulty and gamemode lines marked and the Save button circled](/screenshots/panel-editor-server-properties.webp)

## Popular settings

| Setting | What it does | Example |
|---|---|---|
| `difficulty` | `peaceful`, `easy`, `normal` or `hard` | `difficulty=hard` |
| `hardcore` | Permadeath for a new world, see [Turn on hardcore](#turn-on-hardcore) | `hardcore=true` |
| `gamemode` | Default mode for new players: `survival`, `creative`, `adventure`, `spectator` | `gamemode=survival` |
| `force-gamemode` | If `true`, players are set to the default gamemode on every join | `force-gamemode=true` |
| `pvp` | Whether players can damage each other | `pvp=false` |
| `allow-flight` | Stops the server from kicking players for flying (needed for some mods and plugins) | `allow-flight=true` |
| `view-distance` | How many chunks players can see (range 3 to 32, default 10) | `view-distance=8` |
| `simulation-distance` | How far from a player the world is actively updated | `simulation-distance=6` |
| `max-players` | Player slot limit | `max-players=20` |
| `motd` | The text shown in the server list | see [MOTD](/running_a_server/motd) |
| `white-list` | Only allow listed players | see [Whitelist](/running_a_server/whitelist) |
| `online-mode` | Verify accounts with Mojang | see [Online Mode](/running_a_server/online-mode) |
| `level-seed` | Seed for new worlds | see [Change Your World Seed](/running_a_server/change-world-seed) |
| `enable-command-block` | Allow command blocks on older versions | see [Command Blocks](/running_a_server/enable-command-blocks) |

Lowering `view-distance` and `simulation-distance` is the easiest way to cut lag. Values of 6 to 8 are plenty for most servers.

## Changing things without restarting

Difficulty and gamemode can also be changed in-game with `/difficulty` and `/gamemode`. Changes to `server.properties` itself need a restart.

Allow-flight only matters in survival. Anti-cheats usually need to be told separately that flying is allowed for certain ranks.

## Turn on hardcore

The steps depend on your edition. To test either one, die once: if you can still respawn, the world is not hardcore.

### Minecraft Java

`hardcore=true` in `server.properties` is only used when a world is first made. An existing world keeps its own setting in `level.dat`, so changing the line and restarting does nothing to it.

**For a new world:**

1. Stop the server and make a [backup](/using_the_panel/backups/guide) if you want to keep the old world.
2. In `server.properties`, set `hardcore=true` and `difficulty=hard`, and save.
3. In **Files**, delete the world folders (see [World Reset](/running_a_server/world-reset)), then start the server.

**To keep your current world:**

1. Stop the server and make a backup.
2. In **Files**, open your world folder, then click `level.dat`. It opens in the panel's NBT editor.
3. Under `Data`, set `hardcore` to `1` and `Difficulty` to `3` (Hard). On newer Minecraft versions these can sit in a group such as `difficulty_settings`, with `hard` written as a word.
4. Save and start the server.

### Vanilla Bedrock and Endstone

Hardcore works on both, but it has to be set when the world is created, so you make the world in the game and upload it. An existing Bedrock world can't be switched to hardcore.

1. In Minecraft Bedrock, create a new world with **Hardcore** turned on.
2. Export the world from your world list.
3. Stop the server. In **Files**, upload the world folder into `worlds/`. See [Upload a .mcworld file](/games/minecraft-bedrock/worlds-and-packs#upload-a-mcworld-file-phone-tablet-or-exported-world) for how to turn the export into a folder.
4. In `server.properties`, set `level-name` to that folder's exact name, save, and start the server.
