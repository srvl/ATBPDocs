title: "Basic Server Commands"
description: "Everyday commands every Minecraft server owner should know."
---

Run these in-game as an operator (with a `/` in front) or in the panel **Console** tab (without the `/`). Replace names in angle brackets with real values, such as a player name.

| Command | What it does |
|---|---|
| `op NAME` / `deop NAME` | Give or remove operator status |
| `whitelist on` / `whitelist off` | Turn the whitelist on or off |
| `whitelist add NAME` | Add a player to the whitelist |
| `whitelist remove NAME` | Remove a player |
| `whitelist list` | Show whitelisted players |
| `kick NAME reason` | Remove a player, they can rejoin |
| `ban NAME reason` | Ban a player |
| `pardon NAME` | Unban a player (some plugins use `unban`) |
| `gamemode MODE NAME` | Set gamemode: survival, creative, adventure or spectator |
| `difficulty LEVEL` | Set difficulty |
| `time set day` | Set time; also `noon`, `sunset`, `night` or a number such as 6000 |
| `weather clear` | Set weather; also `rain` and `thunder` |
| `say MESSAGE` | Broadcast a message |
| `list` | Show who is online and how many players are on |
| `seed` | Show the world's seed (works even when `level-seed` in `server.properties` is blank) |
| `save-all` | Force a world save |
| `stop` | Safely stop the server |
| `tps` | Show server speed (20 is perfect), on Paper and forks |

## Game rules

Game rules switch things like keep inventory or mob griefing on and off. Run them the same way: in the **Console** without a `/`, or in-game as an operator with one. Java 1.21.11 and newer renamed the rules to lowercase words with underscores, so the old names no longer work there.

| Setting | Java 1.21.11 and newer | Older Java | Bedrock |
|---|---|---|---|
| Keep items when you die | `gamerule keep_inventory true` | `gamerule keepInventory true` | `gamerule keepinventory true` |
| Mobs break blocks | `gamerule mob_griefing false` | `gamerule mobGriefing false` | `gamerule mobgriefing false` |
| Players who must sleep to skip the night (percent; `1` means one player is enough) | `gamerule players_sleeping_percentage 1` | `gamerule playersSleepingPercentage 1` (1.17 and newer) | `gamerule playerssleepingpercentage 1` |

On a crossplay server (Java with Geyser), use the Java command; Bedrock players follow it too. Not sure of a rule's name? Type `gamerule ` in the in-game chat and press Tab to see the list. If you use Multiverse or a similar world plugin, set the rule in each world.

Use `stop` or the panel Stop button instead of killing the server, so worlds save properly. Avoid `/reload` on servers with plugins. It can break plugins and leak memory. Restart instead.

More help: [Whitelist](/running_a_server/whitelist), [Make Yourself an Operator](/running_a_server/op-yourself), [Enable Command Blocks](/running_a_server/enable-command-blocks).
