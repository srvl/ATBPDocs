---
title: "Updating your Palworld server"
description: "Restart to update, and what to do when the update does not take."
---

When Palworld updates, players cannot join until the server is on the same version.

## Restart to update

Restart the server from the **Console** tab in the [panel](https://panel.atbphosting.com). It checks for a new version while starting and downloads it.

## If it stays on the old version

1. Stop the server and make a backup in the **Backups** tab.
2. In **Files**, delete the `steamapps` folder in the main folder. This only clears the download cache; your world is in `Pal/Saved` and stays.
3. Open **Settings** and press **Reinstall Server**.
4. Start the server once the reinstall finishes.

If the server freezes after an update, see [Palworld performance and common issues](/games/palworld/info#common-issues).
