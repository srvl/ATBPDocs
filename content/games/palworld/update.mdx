---
title: "Updating server"
description: "Learn how to update your server to the latest version of Palworld"
---

## Method 1

Restart the server. The server should update automatically when it restarts. If it doesn't, follow Method 2.

## Method 2

First, stop your server. Then go to the [Backups](/using_the_panel/backups/guide) tab and make a backup in case something goes wrong. After that, go to the Settings tab and click Reinstall.

Server should now start up with the latest version!
