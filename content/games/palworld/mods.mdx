<Callout type="warning">

Mods can crash the server or damage a save. Make a backup first, and add mods a few at a time so you know which one caused a problem.

</Callout>

Every Palworld server has a **Mods** page (under **More**) in the [panel](https://panel.atbphosting.com). It handles both kinds of Palworld mods: Steam Workshop mods (Palworld's own mod system) and pak mods from CurseForge.

## Steam Workshop mods

Only mods made to run on a dedicated server work. A mod's `Info.json` must include `"IsServer": true` in its install rules, and some mods also have to be installed by every player, so read the mod page.

Steam only lets the owner of the game download Workshop files, so you upload them once:

1. Subscribe to the mods on the Palworld Steam Workshop and launch the game once so Steam downloads them.
2. On your PC, open `Steam\steamapps\workshop\content\1623730`. Each numbered folder is one mod with an `Info.json` inside.
3. Select those folders and zip them together.
4. In the panel, open **Files**, create the folders `Mods/Workshop` in the main folder, upload the zip into `Mods/Workshop` and choose **Unarchive**. Each mod should end up as `Mods/Workshop/<folder>/Info.json`.
5. Open **Mods**, then the **Workshop** tab. Your mods are listed with their version; ones not made for servers are marked.
6. Turn on **Load mods**, switch on the mods you want, use the arrows to set the load order, and press **Save**.
7. Restart the server. Loaded mods appear under `Mods/ManagedMods`.

The Workshop tab writes `bGlobalEnableMod` and the `ActiveModList` lines in `Mods/PalModSettings.ini` for you and leaves the rest of the file alone. To update a mod, upload the new version over its folder and restart. To start without any mods, turn off **Load mods**.

## Pak mods from CurseForge

1. In **Mods**, stay on **Browse** with **Pak mods** selected, and search by category, game version or name.
2. Click a mod and pick a version. Versions made for an older Palworld are marked **Old**: old pak mods can stop the server from starting, so prefer one made for the current game version.
3. Press **Install**, then restart the server. The page unpacks the download and puts the `.pak` files in `Pal/Content/Paks/~mods`.

Most pak mods only change what players see, so each player needs them too. Mods that change rules, like rates or stack sizes, work from the server. **Installed** lists every mod with its version and updates, and **Remove** deletes all the files it placed.

Lua, Blueprint and C++ mods on CurseForge need the UE4SS loader, which only runs on Windows servers. Our Palworld servers run on Linux, so the page says when a mod needs it. Ask in a ticket if a mod you need depends on UE4SS.

## Not loading?

- For Workshop mods, check the mod supports dedicated servers (`"IsServer": true`) and that it is switched on in the Workshop tab.
- If the server stopped starting after you added a pak mod, remove it under **Installed** and restart.
- Check the console for errors after a restart.
