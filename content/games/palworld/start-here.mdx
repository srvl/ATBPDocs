Never run a server before? Follow this page from top to bottom.

**You need:** Palworld on each player's PC or console. Everyone must be on the same version as the server.

## 1. Log in to the game panel

Your server runs on the game panel at https://panel.atbphosting.com, not on the billing site. They are separate accounts with separate passwords.

- Your panel login is the email in the **"Your server is ready"** message. Check spam if you cannot find it.
- No panel password yet? Look for the email titled **Panel password inside**, or press **Forgot password** on the panel login page.
- From billing you can also open **Services**, pick your server and press **Manage server**.

Everything is in your browser. There is no remote desktop, and you do not install the server on your own computer.

## 2. Start the server

Press **Start** on the **Console** tab. The first start downloads the game and takes a while. It is ready when the console stops scrolling.

## 3. Join

1. Copy the IP address and port from the **Console** or **Network** tab.
2. In Palworld, choose **Join Multiplayer Game**.
3. Paste the address in the box at the bottom and press **Connect**.

Do not search for your server in the community list. It is slow and often misses servers. See [Join your Palworld server](/games/palworld/connecting).

## 4. Set your admin and join passwords

Set them on the **Startup** tab if listed there, or in `PalWorldSettings.ini`. Always stop the server first, or your changes are lost. See [Palworld server settings](/games/palworld/config).

Then in game chat, type `/AdminPassword yourpassword` to become admin. See [admins and commands](/games/palworld/admin).

## 5. Keep it smooth

Palworld's memory climbs the longer it runs. Set a [schedule](/using_the_panel/schedules) to restart every 6 hours. See [Performance and common issues](/games/palworld/info).

## 6. Bring your world and mods

- [Upload or move a world](/games/palworld/worlds)
- [Install mods](/games/palworld/mods) from **More**, **Mods**

## Common problems

| Problem | Fix |
| --- | --- |
| Settings reset after a restart | Stop the server fully before editing. If you uploaded a world, check `WorldOption.sav`. See [settings](/games/palworld/config). |
| Cannot join after a game update | Restart the server to update it. See [Updating](/games/palworld/update). |
| Host's character is gone after uploading a co-op world | See [Co-op worlds](/games/palworld/worlds#co-op-worlds-and-the-hosts-character). |
| "Incorrect password" with no prompt | See [Set a server password](/games/palworld/connecting#set-a-server-password). |

## Keep it safe

- Set a backup schedule in the **Backups** tab, and make a backup before any big change. See [Backups](/using_the_panel/backups/guide).
- Big uploads: one upload through the panel can be up to 1 GB on Budget+ and 100 GB on Premium+. Use [SFTP](/using_the_panel/sftp) for anything bigger. Your SFTP password is your game panel password.
- Wrong game or version? You can change it yourself in **Settings**, **Change Game**.

## Still stuck?

Open a ticket on our [Discord](https://discord.atbphosting.com) with your panel link and the error from the **Console**. See [How to get support](/general/getting-support). Never post your password in a ticket.
