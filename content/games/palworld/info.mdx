## Known Issues / FAQ

1. **The server won't show up in the Community-Server tab**:
   - This is a known problem that the developers will hopefully fix soon. The best choice is to connect by IP and password.
2. **The server has a memory leak**:
   - The developers are aware of this issue too.
   - The `bEnableInvaderEnemy` option seems to have a huge impact on RAM usage. Disabling it can help.
   - Schedule a server restart every 6 hours, and adjust the interval to suit your server.
3. **The server does not show up in the steam server list**:
   - This is not supported right now and might never be.
4. **The config file gets deleted / reset on server restart**:
   - Before editing the config file always make sure to fully stop the server first. Otherwise your changes will not be saved.

## Recommended Server Limits

Palworld uses more memory the longer it runs, so pick a size with some headroom and restart the server regularly.

| Players | RAM |
|---|---|
| Up to 6 | 8 GB |
| 8 to 16 | 10 to 12 GB |
| Up to 32 | 16 GB |

- Set a [schedule](/using_the_panel/schedules) to restart the server every 6 hours (or daily for small groups). This clears the memory build-up before players notice lag.
- Turning off `bEnableInvaderEnemy` lowers memory use noticeably.
- The game itself needs about 5 GB of disk; every ATBP Palworld plan has at least 80 GB of NVMe (10 GB per 1 GB of RAM), so worlds and backups have plenty of room.
