---
title: "Join your 7 Days to Die server"
description: "Connect by server name or by direct IP and port."
---

1. Open 7 Days to Die and click **Join a Game**.
2. Pick a method.

## Direct IP (recommended)

Click **Connect to IP**, enter the IP and port from the [panel](https://panel.atbphosting.com), and click **Connect**. The default game port is `26900`, but use the one shown for your server.

## Server name

Use the exact `ServerName` from `serverconfig.xml`, type it into the server name search, click **Start search**, then select your server and **Connect**. The public list can be slow to refresh, so direct IP is more reliable.

## Troubleshooting

- Wait for the server to finish booting in the **Console** tab.
- Recheck the IP and port.
- Your game and the server must be on the same version. Update through Steam.
- Not in the list: use direct IP.
