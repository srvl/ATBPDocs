## Where the files are

In the [panel](https://panel.atbphosting.com), open **Files**, then the `.cache` folder and the `Server` folder. You will find two files named after your server:

- `<name>.ini` for general settings
- `<name>_SandboxVars.lua` for gameplay settings

Open each, edit, and use **Save Content**. Then start the server from the **Console**.

## Common settings in the .ini file

- `MaxPlayers=` how many players at once
- `Password=` join password, blank for public
- `PublicName=` name in the public browser
- `GlobalChat=false` turns the global chat off

## Common settings in the SandboxVars file

- `Zombies =` population: 1 Insane, 2 Very High, 3 High, 4 Normal, 5 Low, 6 None
- `ElecShutModifier =` and `WaterShutModifier =` the in-game day power and water go off. Power is on while the world is on that day or earlier. `14` is the default, `-1` means no power from the first day, and a large number such as `100000` keeps it on.
- `ElecShut =` and `WaterShut =` only matter when a world is made in the game's own menu. On your server they do nothing, so change the `Modifier` lines instead.
- `XPMultiplier =` for example `2.0` is double XP
- Loot options such as `FoodLoot=` and `WeaponLoot=`: 1 Extremely Rare, 2 Rare, 3 Normal, 4 Common

If the server will not start after an edit, a typo in the file is the usual cause. Ask in a ticket on our [Discord](https://discord.atbphosting.com) if you are stuck.
