---
title: "Join your Project Zomboid server"
description: "Add your server in the Multiplayer menu and create your account."
---

1. In the [panel](https://panel.atbphosting.com), copy your server's **IP address** and **port**. They are shown together as `ip:port`. Use the port the panel shows: our servers do not use the game's default `16261`.
2. Start Project Zomboid and choose **Multiplayer**.
3. On the **Favorites** tab, click **Add Server**.
4. Fill in a name, the IP (or your domain), and the port. Only fill the **server password** if you set one. Save.
5. Click **Add New Account** under your server, choose a username and an **account password**, and leave authentication on **Password**. Save.
6. Click **Connect** next to your account.

The server password and the account password are different things. The server password lets you in; the account password protects your own character.

Ticking **Use Steam Relay** routes your connection through Steam so your IP is not shown to server admins.

## Troubleshooting

- Make sure the server is online in the panel.
- Keep the IP and port in separate boxes.
- Stuck on **Getting Server Info**: the server is using a port it does not have. See [Getting Server Info](/games/project-zomboid/troubleshooting#stuck-on-getting-server-info).
- Version or mod mismatch: update the game fully and install the same mods as the server.
- A rejected server password means you typed it in the account password box, or the reverse.
