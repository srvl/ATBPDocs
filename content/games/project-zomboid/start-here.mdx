Never run a server before? Follow this page from top to bottom.

**You need:** Project Zomboid on each player's PC through Steam, on the same build as the server.

## 1. Log in to the game panel

Your server runs on the game panel at https://panel.atbphosting.com, not on the billing site. They are separate accounts with separate passwords.

- Your panel login is the email in the **"Your server is ready"** message. Check spam if you cannot find it.
- No panel password yet? Look for the email titled **Panel password inside**, or press **Forgot password** on the panel login page.
- From billing you can also open **Services**, pick your server and press **Manage server**.

Everything is in your browser. There is no remote desktop, and you do not install the server on your own computer.

## 2. Start it once

Press **Start** on the **Console** tab and let it finish. This makes your settings files. The first start downloads the game, and any mods, so it can take a while.

## 3. Join

1. Copy the IP and port from the panel. Our servers do not use the game's default port.
2. In the game, choose **Multiplayer**, **Favorites**, **Add Server**. Put the IP and port in their own boxes.
3. Click **Add New Account**, choose a username and account password, and save.
4. Click **Connect**.

The server password lets you in. The account password protects your character. They are different. See [Join your Project Zomboid server](/games/project-zomboid/connecting).

## 4. Make yourself admin

While you are online, run this in the **Console**, with your exact username:

```
SetAccessLevel YourName admin
```

See [admin and staff roles](/games/project-zomboid/admin).

## 5. Change settings

Stop the server, then edit the files in `.cache/Server`: the `.ini` for server settings and `_SandboxVars.lua` for gameplay. See [Project Zomboid server settings](/games/project-zomboid/config).

## 6. Add mods

Use **Mods** in the panel, paste Workshop links or a collection, press **Save**, and restart. See [Install mods](/games/project-zomboid/mods) and [How much RAM do I need?](/games/project-zomboid/ram).

## 7. Bring your world

See [Move a save or reset your world](/games/project-zomboid/saves).

## Common problems

| Problem | Fix |
| --- | --- |
| Stuck on "Getting Server Info" | Zomboid needs two ports. See [Getting Server Info](/games/project-zomboid/troubleshooting). |
| Mod or version mismatch | Everyone must use the same build and mods. See [Builds and common errors](/games/project-zomboid/troubleshooting). |
| Server password rejected | You typed it in the account password box, or the reverse. |
| Slow first join | Players download all the mods first. |

## Keep it safe

- Set a backup schedule in the **Backups** tab, and make a backup before any big change. See [Backups](/using_the_panel/backups/guide).
- Big uploads: one upload through the panel can be up to 1 GB on Budget+ and 100 GB on Premium+. Use [SFTP](/using_the_panel/sftp) for anything bigger. Your SFTP password is your game panel password.
- Wrong game or version? You can change it yourself in **Settings**, **Change Game**.

## Still stuck?

Open a ticket on our [Discord](https://discord.atbphosting.com) with your panel link and the error from the **Console**. See [How to get support](/general/getting-support). Never post your password in a ticket.
