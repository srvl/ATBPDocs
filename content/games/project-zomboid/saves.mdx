<Callout type="warning">

Stop the server before uploading or deleting anything. These tasks replace or erase your world, so download a backup first. See [backups](/plans/backups).

</Callout>

Your server's name is the name of its `.ini` file in `.cache/Server`, `servertest` by default. Everything below is in **Files** in the [panel](https://panel.atbphosting.com). One upload through the panel can be up to 1 GB on Budget+ and 100 GB on Premium+. Use [SFTP](/using_the_panel/sftp) for anything bigger.

## Move a co-op save to the server

1. On your PC, open `Zomboid/Saves/Multiplayer`. On Windows that is `C:\Users\YourName\Zomboid\Saves\Multiplayer`. Each world has a folder named after the name you gave it when hosting.
2. Compress the **contents** of that world folder into one `.zip`. It includes files like `map_*.bin` and `players.db`.
3. In **Files**, open `.cache`, `Saves`, `Multiplayer`, and the folder named after your server.
4. Delete only the default `map_*.bin` files and `players.db` made on first boot, upload your zip, and extract it so the files sit directly in that folder.
5. If you used mods, add the same ones on the **Mods** page, see [mods](/games/project-zomboid/mods).
6. Start the server and join to check your world and character.

Troubleshooting: a brand-new empty world means the folder name does not match the server name. A crash on start usually means mods do not match. Missing character: check `players.db` was included.

## Move a whole dedicated server

Moving from another host or your own dedicated server? Bring these files from the old server's `Zomboid` folder. On ATBP they go in `.cache`, in the same folders:

| File or folder | What it holds |
| --- | --- |
| `Saves/Multiplayer/<name>` | The world and characters |
| `db/<name>.db` | Player accounts, passwords and admin roles |
| `Server/<name>.ini` | Server settings and mod list |
| `Server/<name>_SandboxVars.lua` | Sandbox settings such as zombie count and loot |
| `Server/<name>_spawnregions.lua`, `Server/<name>_spawnpoints.lua` | Spawn settings |

Keep the same `<name>`, or rename every file and the world folder to match your ATBP server name. Use the same game build as the old server. After you upload, open the `.ini` and check the ports match your **Network** tab. Start the server once and let it download the mods.

## Reset the map

1. Stop the server.
2. In **Files**, open `.cache`, then `Saves`, `Multiplayer`, and delete the folder named after your server.
3. Start the server. A fresh world is generated and your mods and settings stay. Player accounts stay too, because they are in `.cache/db`.

The panel has no reset button, and deleting that one folder is all a map reset needs. Leave the files in `.cache/Server` alone: the `.ini` holds your mod list and `_SandboxVars.lua` holds your sandbox settings, so deleting them gives you a server with no mods and default settings. If the `.ini` was deleted, look for a `.ini.bak` next to it and copy its `Mods=`, `WorkshopItems=` and `Map=` lines into the new `.ini`, then save and start the server.

Change sandbox settings such as zombie count in `_SandboxVars.lua` first, then reset the map so the new world starts with them. The power and water days are the exception: the server checks them against the world's current day each time it starts, so a restart is enough for those.

For a full reset that also removes settings and mods, open a ticket on our [Discord](https://discord.atbphosting.com) so we can reinstall the server for you.
