## With the Mods page

Every Hytale server has a **Mods** page in the [panel](https://panel.atbphosting.com) that installs straight from CurseForge.

1. Open your server and choose **More > Mods**.
2. Pick **Mods** or **Early plugins**, then narrow the list by category, game version or name.
3. Click a mod, choose a version (the newest is picked for you) and press **Install**. Mods it needs are installed with it.
4. Restart the server to load it.

Under **Installed** you see every mod with its version, which mods need it, and a badge when an update is out. Open a mod to switch to another version, or press **Remove** to delete its files. Files you uploaded yourself are listed under **Added by hand**.

Early plugins only load when **Accept Early Plugins** is turned on in the **Startup** tab; the page reminds you when it is off. A few authors only allow downloads from the CurseForge site; those mods show a link there instead of an install button, so download them and upload them as below.

## Upload it yourself

1. Download the mod or plugin, usually a `.jar`, from a trusted source.
2. Stop the server, open **Files** and upload gameplay mods to the `mods` folder and server management plugins to `earlyplugins` (create the folder if it is missing).
3. Start the server and check the startup log for a message that it loaded.

## On your PC

- **CurseForge app:** choose Hytale, search for the mod, press **Install**, then **Play**.
- **Manually:** put the `.jar` in `%appdata%\Hytale\UserData\Mods`, creating the `Mods` folder if needed.

If the server crashes on startup, remove the newest mod and check it matches the game version. For a bug in one plugin, contact its author.
