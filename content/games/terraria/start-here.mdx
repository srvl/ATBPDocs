Never run a server before? Follow this page from top to bottom.

**You need:** Terraria on each player's PC or device. For tModLoader, every player also needs tModLoader and the same mods.

## 1. Log in to the game panel

Your server runs on the game panel at https://panel.atbphosting.com, not on the billing site. They are separate accounts with separate passwords.

- Your panel login is the email in the **"Your server is ready"** message. Check spam if you cannot find it.
- No panel password yet? Look for the email titled **Panel password inside**, or press **Forgot password** on the panel login page.
- From billing you can also open **Services**, pick your server and press **Manage server**.

Everything is in your browser. There is no remote desktop, and you do not install the server on your own computer.

## 2. Choose your world before the first start

Open the **Startup** tab and set **World Name**, size, difficulty and seed. Size and difficulty are fixed once the world is made. Journey worlds only accept Journey characters. See [Worlds](/games/terraria/worlds).

Already have a world? Upload the `.wld` file to `saves/Worlds` and set **World Name** to match it.

## 3. Start the server

Press **Start** on the **Console** tab. Making a new world takes a few minutes. Wait until the console says the server is listening.

## 4. Join

1. Copy the **IP address** and port from the panel.
2. In Terraria, open **Multiplayer**, then **Join via IP**, and pick your character.
3. Enter the IP without the port, then the port on its own. See [Connecting](/games/terraria/connecting).

## 5. Add a password

Set **Server Password** on the **Startup** tab and restart. See [Using a server password](/games/terraria/password).

## 6. Manage players

Vanilla servers are managed from the **Console**, with no slash: see [commands](/games/terraria/commands). For in-game admin tools, use [TShock](/games/terraria/tshock/overview). For mods, use [tModLoader](/games/terraria/tmodloader/overview).

## Common problems

| Problem | Fix |
| --- | --- |
| My world reset to a new one | **World Name** does not match your file. See [My world reset](/games/terraria/worlds#my-world-reset-to-a-brand-new-one). |
| Players cannot join after a game update | Stop, back up and press **Reinstall Server** under **Settings**. Worlds and mods stay. Players must update too. |
| Character cannot join | Journey characters only join Journey worlds, and the other way round. |

## Keep it safe

- Set a backup schedule in the **Backups** tab, and make a backup before any big change. See [Backups](/using_the_panel/backups/guide).
- Big uploads: one upload through the panel can be up to 1 GB on Budget+ and 100 GB on Premium+. Use [SFTP](/using_the_panel/sftp) for anything bigger. Your SFTP password is your game panel password.
- Wrong game or version? You can change it yourself in **Settings**, **Change Game**.

## Still stuck?

Open a ticket on our [Discord](https://discord.atbphosting.com) with your panel link and the error from the **Console**. See [How to get support](/general/getting-support). Never post your password in a ticket.
