Never run a server before? Follow this page from top to bottom.

**You need:** A copy of GTA V on each player's PC, the FiveM client, and a free Cfx.re account for your license key.

## 1. Log in to the game panel

Your server runs on the game panel at https://panel.atbphosting.com, not on the billing site. They are separate accounts with separate passwords.

- Your panel login is the email in the **"Your server is ready"** message. Check spam if you cannot find it.
- No panel password yet? Look for the email titled **Panel password inside**, or press **Forgot password** on the panel login page.
- From billing you can also open **Services**, pick your server and press **Manage server**.

Everything is in your browser. There is no remote desktop, and you do not install the server on your own computer.

## 2. Get your license key

If you did not enter one when you ordered, follow [Set up your FiveM server](/games/fivem/getting-started) and paste the `cfxk_` key on the **Startup** tab.

## 3. Start the server and open txAdmin

1. Press **Start** and watch the **Console**. The panel shows **starting** until setup is finished. That is normal.
2. The console shows a 4-digit **PIN**. Open txAdmin from **More**, **FiveM**, **Tools**, or at your IP with the txAdmin port from the **Network** tab.
3. Enter the PIN, sign in with Cfx.re and create your admin password.

See [Open txAdmin](/games/fivem/txadmin).

## 4. Choose how to set it up

| You want | Choose |
| --- | --- |
| A ready roleplay server | **Popular Recipes**, then Qbox, QBCore or ESX. Create a database first, see [Set up your FiveM database](/games/fivem/database). |
| A plain test server | **Popular Recipes**, then CFX Default |
| The server you already have | **Existing Server Data**. Follow [Move an existing server](/games/fivem/migrating-an-existing-server). |

## 5. Join

Press **F8** in FiveM and type `connect` with your IP and main port from the **Network** tab. See [Connect to your FiveM server](/games/fivem/connecting).

## 6. Add scripts, cars and maps

Use the **FiveM** page under **More**, or upload them. See [Add resources and frameworks](/games/fivem/resources). Use txAdmin's **Live Console** to read errors and type commands.

## Common problems

See [FiveM troubleshooting](/games/fivem/troubleshooting).

## Keep it safe

- Set a backup schedule in the **Backups** tab, and make a backup before any big change. See [Backups](/using_the_panel/backups/guide).
- Big uploads: one upload through the panel can be up to 1 GB on Budget+ and 100 GB on Premium+. Use [SFTP](/using_the_panel/sftp) for anything bigger. Your SFTP password is your game panel password.
- Wrong game or version? You can change it yourself in **Settings**, **Change Game**.

## Still stuck?

Open a ticket on our [Discord](https://discord.atbphosting.com) with your panel link and the error from the **Console**. See [How to get support](/general/getting-support). Never post your password in a ticket.
