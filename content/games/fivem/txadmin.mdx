txAdmin is the web panel that runs your FiveM server. You use it to start and restart FiveM, manage players and bans, add resources and schedule restarts. It is turned on for every ATBP FiveM server and runs on its own port.

## First login

1. Start the server in the [panel](https://panel.atbphosting.com) and watch the **Console**.
2. When txAdmin is ready, the console shows a 4-digit **PIN**.
3. Open txAdmin in your browser: your server's IP with the txAdmin port, for example `http://123.45.67.89:40123`. The **Network** tab lists both ports; the txAdmin port is also shown on the **Startup** tab as `TXHOST_TXA_PORT`.
4. Enter the PIN, then sign in with your Cfx.re account and create your txAdmin admin password.

The PIN only works once and changes when the server restarts. If it expired, restart the server and use the new one.

## Set up the server

txAdmin asks how you want to set up FiveM:

- **Popular recipes**: installs a ready server, for example QBCore or ESX for roleplay, or a plain CFX default server. This is the easiest start.
- **Existing server data**: use this if you uploaded your own server files.

Follow the steps, keep the suggested data folder, and let it finish. txAdmin then starts FiveM for you.

## Good to know

- Start, stop and restart FiveM from txAdmin. Use the panel's buttons only for the whole server, for example after changing the license key.
- Add other people as admins in txAdmin under **Admins**, so you never share your own login.
- Set automatic restarts in txAdmin under **Settings**. A restart every 6 to 12 hours keeps busy roleplay servers running smoothly.
