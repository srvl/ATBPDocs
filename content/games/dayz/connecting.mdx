---

Get your **IP address** and **game port** from the server's Overview in the [panel](https://panel.atbphosting.com).

The **query port** (in the game settings) only makes the server visible in the Steam browser. Do not enter it in Direct Connect.

## Direct Connect (fastest)

1. Open DayZ and click **Servers**.
2. Click **Direct Connect** at the bottom right.
3. Enter the IP and the **game port**, then click **Connect**.

## Community list

Open **Servers**, then **Community**, search for your server's name and click **Join**. A new or just restarted server can take a few minutes to appear. Direct Connect works as soon as it has fully started.

If the server has a password, you are asked for it. Tick **Add to Favorites** so you do not need to type it again.

## Troubleshooting

- Not in the list: normal for new servers, use Direct Connect.
- Timeout: check for typos, make sure you used the game port, and that the server shows as started.
- Version mismatch: let Steam finish updating DayZ.
- Kicked on joining: the server uses mods, so install the same ones, see [mods](/games/dayz/mods).
