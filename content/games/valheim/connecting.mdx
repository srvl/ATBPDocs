## PC

1. In the [panel](https://panel.atbphosting.com), copy your server's IP address and port.
2. Start Valheim, press **Start Game**, and pick your character.
3. Open the **Join Game** tab and choose **Add Server**.
4. Paste the IP and port exactly as shown, with no extra spaces, and click **Connect**.
5. Enter the server password if asked. Passwords are case-sensitive.

## Console (Xbox, PlayStation, Switch 2)

Consoles do not use IP and port. The server makes a **six-digit join code** each time it starts. Find it in the last lines of the **Console** tab once the server has finished booting, then choose **Join Game** and the join code option on your console. The code changes on every restart.

PC players keep using IP and port on the same server.

<Callout type="info">

A brand-new server can have a default password set at install. Check the password in the server's settings or startup page in the panel and change it to your own.

</Callout>

## Troubleshooting

- Make sure the server shows as online.
- Check for typos in the IP and port.
- Check the password.
- Make sure your firewall or antivirus is not blocking Valheim.
