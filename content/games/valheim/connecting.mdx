## PC

1. In the [panel](https://panel.atbphosting.com), copy your server's IP address and port.
2. Start Valheim, press **Start Game**, and pick your character.
3. Open the **Join Game** tab and choose **Add Server**.
4. Paste the IP and port exactly as shown, with no extra spaces, and click **Connect**.
5. Enter the server password if asked. Passwords are case-sensitive.

## Console and Game Pass (crossplay)

Crossplay is **off** on our Valheim servers. Xbox, PlayStation, Switch 2 and PC Game Pass players join through Microsoft PlayFab, and PlayFab connections from our network do not work yet, so a server with crossplay on never finishes starting. Play on PC through Steam for now. We will update this page when crossplay works.

<Callout type="info">

The server password is the one you typed at checkout (5 to 20 letters or numbers). Change it any time in the **Startup** tab of the panel. Valheim refuses a password that is part of the server name.

</Callout>

## Troubleshooting

- Make sure the server shows as online.
- Check for typos in the IP and port.
- Check the password.
- Make sure your firewall or antivirus is not blocking Valheim.
