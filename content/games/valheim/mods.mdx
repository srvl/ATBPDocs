---
title: "Install mods on Valheim"
description: "Upload BepInEx mods to your server and what players need to do."
---

Most Valheim mods run on BepInEx. Before you start, confirm in **Files** that your server has a `BepInEx` folder. If it does not, ask in a ticket on our [Discord](https://discord.atbphosting.com).

## Manual install

1. Download the mod from a site like Thunderstore or NexusMods and extract the `.dll` file.
2. Stop the server in the [panel](https://panel.atbphosting.com).
3. Open **Files**, then `BepInEx`, then `plugins`, and upload the `.dll`.
4. Start the server. BepInEx loads the mod automatically.

## Remember

- Most mods must also be installed on every player's game.
- The mod must match the current Valheim version.
- If a mod seems inactive, check it is directly in `BepInEx/plugins` and read the console for errors.
