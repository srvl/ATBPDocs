## Make someone owner or moderator

You need the player's Steam64 ID; see [Find your Steam ID](/extras/steam-id).

1. Open the **Console** tab of your server in the [panel](https://panel.atbphosting.com).
2. Run one of these:

| Command | Access |
| --- | --- |
| `ownerid 76561198000000000 "Name"` | Full admin, can add other admins |
| `moderatorid 76561198000000000 "Name"` | Admin commands, cannot add admins |

3. Run `server.writecfg` so the list is saved and survives restarts.
4. Rejoin the server. Press `F1` in game to open the console.

To take it away, use `removeowner <id>` or `removemoderator <id>`, then `server.writecfg`.

## Ban and unban

Run these in the panel **Console**, or in the `F1` console in game as an admin.

| Command | What it does |
| --- | --- |
| `kick <name or id> "reason"` | Removes a player |
| `kickall "reason"` | Removes everyone |
| `ban <name> "reason"` | Bans an online player |
| `banid <steamid> "name" "reason"` | Bans by Steam ID, online or not |
| `unban <steamid>` | Lifts a ban. Only works with the Steam ID |
| `banlistex` | Lists bans with reasons |

Bans are saved with `server.writecfg`.

## Other useful commands

| Command | What it does |
| --- | --- |
| `status` | Online players with IDs and ping |
| `say "message"` | Message in chat to everyone |
| `server.save` | Save the world now |
| `restart 300 "reason"` | Restart with a 5 minute countdown in chat |
| `env.time 12` | Set the time of day (0 to 24) |
| `weather.rain 0` | Stop rain |
| `teleport <player>`, `teleport2me <player>` | Move to a player, or bring them to you (in game) |
| `noclip`, `god true` | Fly and take no damage (in game, admins only) |
| `server.writecfg` | Save admin, ban and settings changes |

## Private server with a whitelist

Rust has no built-in whitelist. Use the free **Whitelist** plugin from uMod:

1. Turn on Oxide and learn how to add plugins in [Using plugins](/games/rust/plugins).
2. Upload `Whitelist.cs` to `oxide/plugins` and restart. From now on only allowed players can join.
3. Allow a player: `oxide.grant user <steamid> whitelist.allow`
4. Remove a player: `oxide.revoke user <steamid> whitelist.allow`

For many players, make an Oxide group, grant the group `whitelist.allow`, and add players to the group with `oxide.usergroup add <steamid> <group>`.

## Remote console tools

Desktop tools such as RustAdmin connect over Rust's WebRCON so staff can run commands without the panel. They need your server IP, the RCON port and the RCON password, which you set on the **Startup** tab. Use a long password; anyone with it controls the server.
